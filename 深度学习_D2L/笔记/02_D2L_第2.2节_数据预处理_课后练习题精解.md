## 一、创建包含更多行列的原始数据集

我们构建一个包含 6 行 5 列的房地产模拟数据集，涵盖数值特征（房间数 `NumRooms`、建造年份 `YearBuilt`、房屋售价 `Price`）以及离散类别特征（屋顶类型 `RoofType`、是否有花园 `HasGarden`）。在不同字段上故意设置不同比例的缺失值（`NaN`）：

```python
import numpy as np
import pandas as pd
import torch

data = {
    'NumRooms': [3.0, 2.0, np.nan, 4.0, 3.0, np.nan],            # 2 个缺失
    'RoofType': ['Slate', np.nan, 'Tile', 'Slate', np.nan, 'Tile'], # 2 个缺失
    'YearBuilt': [2005, 1998, 2015, np.nan, 2020, 1980],          # 1 个缺失
    'HasGarden': [np.nan, 'Yes', np.nan, np.nan, np.nan, 'No'],   # 4 个缺失 (最多!)
    'Price': [350000, 280000, 420000, 500000, 390000, 210000]    # 0 个缺失 (目标列)
}

df = pd.DataFrame(data)
print("【原始数据集】\n", df)
```

```text
3       4.0    Slate        NaN       NaN  500000
4       3.0      NaN     2020.0       NaN  390000
5       NaN     Tile     1980.0        No  210000
```

## 二、第 1 题：删除缺失值最多的列

### 2.1 统计每列缺失值并自动定位
在实际工业级数据流中，避免硬编码列名，推荐使用自动化检索：

```python
# 1. 统计每一列中 NaN 的数量
missing_counts = df.isnull().sum()
print("【各列缺失值数量】:\n", missing_counts)

# 2. 找到缺失值最多的列名 (idxmax)
max_nan_col = missing_counts.idxmax()
print(f"\n缺失值最多的列为: '{max_nan_col}' (缺失 {missing_counts[max_nan_col]} 条)")

# 3. 使用 drop 函数删除该列
df_dropped = df.drop(columns=[max_nan_col])
print("\n【删除缺失最多列后的数据】:\n", df_dropped)
```

**输出结果**：

## 三、第 2 题：将预处理后的数据集转换为张量格式

要顺利转换为 PyTorch 张量，必须解决剩下的两类问题：
1. **剩余的数值型缺失值（NaN）**：深度学习模型不能直接输入 NaN，通常使用**均值插值法（Mean Imputation）**填充。
2. **离散类别型特征（RoofType）**：模型只能处理数字，不能处理英文字符串，需要使用**独热编码（One-Hot Encoding）**，并将缺失的类别也作为独立的一项（`dummy_na=True`）。

### 3.1 预处理完整执行代码
```python
# 1. 对所有连续数值型列，采用列均值进行插值填充
numeric_cols = df_dropped.select_dtypes(include=[np.number]).columns
df_dropped[numeric_cols] = df_dropped[numeric_cols].fillna(df_dropped[numeric_cols].mean())

# 2. 对离散类别特征进行独热编码 (One-Hot)，把 NaN 也当作合法类别编码
df_processed = pd.get_dummies(df_dropped, dummy_na=True, dtype=float)
print("【预处理完备的数值表格】:\n", df_processed)

# 3. 转换为 PyTorch 张量格式
tensor_data = torch.tensor(df_processed.to_numpy(dtype=float))
print("\n【转换后的 PyTorch 张量】:\n", tensor_data)
print("张量形状:", tensor_data.shape)
print("张量数据类型:", tensor_data.dtype)
```

## 四、核心方法总结速查表

| 操作任务 | 推荐最佳实践代码 | 核心说明 |
| :--- | :--- | :--- |
| **统计全表缺失** | `df.isnull().sum()` | 按列汇总 NaN 个数 |
| **定位最多缺失** | `df.isnull().sum().idxmax()` | 自动返回缺失最大的列名 |
| **删除指定字段** | `df.drop(columns=[col_name])` | 列轴删除，生成新 DataFrame |
| **数值缺失填充** | `df[cols].fillna(df[cols].mean())` | 均值插值法保留整体分布 |
| **类别离散编码** | `pd.get_dummies(..., dummy_na=True)` | 独热展开，同时保留缺失信息 |
| **张量格式转换** | `torch.tensor(df.to_numpy())` | 转为 PyTorch 训练所需张量格式 |
