## 1. Pandas 数据提取：`data.iloc[:, 0:2]` 深度拆解

在数据预处理阶段，我们经常需要将原始表格数据拆解为**“输入特征（Features, $X$）”**和**“预测目标（Labels, $y$）”**。

### 1.1 语法规则：`data.iloc[行切片, 列切片]`
* **逗号 `,` 是分水岭**：逗号左边控制**行**，逗号右边控制**列**。
* **左侧 `:`（行选择）**：单独一个冒号代表**“全选”**，即提取所有样本行（从第 0 行到最后一行）。
* **右侧 `0:2`（列选择）**：遵循 Python 标准切片的**“左闭右开”**原则，提取**第 0 列和第 1 列**（共 2 列），不包含索引为 2 的那一列。

### 1.2 经典特征与标签分离范式
假设数据表包含房间数、巷子类型及房价：
```python
# 1. 取出前两列特征（房间数、巷子类型），作为模型输入 X
inputs = data.iloc[:, 0:2]

# 2. 取出最后一列（售价），作为模型预测目标 y
outputs = data.iloc[:, 2]
```

## 2. 张量降维求和：`A.sum(axis=...)` 到底是怎么算的？

很多初学者容易被教材中的“输入轴 $k$ 的维数在输出形状中消失”绕晕。其实本质非常直观：**指定哪个轴，就是顺着哪个物理方向把数据压扁合并！**

### 2.1 案例矩阵 $A$（5 行 4 列）
假设矩阵 $A = \text{arange}(20).\text{reshape}(5, 4)$，其内部真实数字分布如下：

```text
               第0列   第1列   第2列   第3列
    第 0 行: [   0,      1,      2,      3   ]
    第 1 行: [   4,      5,      6,      7   ]
    第 2 行: [   8,      9,     10,     11   ]
    第 3 行: [  12,     13,     14,     15   ]
    第 4 行: [  16,     17,     18,     19   ]
```
* **原形状**：`shape = [5, 4]`
* **轴 0（axis=0）**：垂直向下的方向（跨越 5 行）
* **轴 1（axis=1）**：水平向右的方向（跨越 4 列）

---

### 2.2 `A.sum(axis=0)`：千斤顶自上而下压扁（列求和）

* **计算方式**：顺着垂直向下的方向，将每一列内部的 5 个数字纵向相加：
  * 第 0 列：$0 + 4 + 8 + 12 + 16 = \mathbf{40}$
  * 第 1 列：$1 + 5 + 9 + 13 + 17 = \mathbf{45}$
  * 第 2 列：$2 + 6 + 10 + 14 + 18 = \mathbf{50}$
  * 第 3 列：$3 + 7 + 11 + 15 + 19 = \mathbf{55}$
* **计算结果**：`tensor([40., 45., 50., 55.])`
* **形状变化**：`[5, 4]` ➡️ 垂直压扁 ➡️ `[4]`（第 0 维的“5”被压平消除，输出长度为 4 的一维向量）。

---

### 2.3 `A.sum(axis=1)`：推土机自左往右推平（行求和）

* **计算方式**：顺着水平向右的方向，将每一行内部的 4 个数字横向相加：
  * 第 0 行：$0 + 1 + 2 + 3 = \mathbf{6}$
  * 第 1 行：$4 + 5 + 6 + 7 = \mathbf{22}$
  * 第 2 行：$8 + 9 + 10 + 11 = \mathbf{38}$
  * 第 3 行：$12 + 13 + 14 + 15 = \mathbf{54}$
  * 第 4 行：$16 + 17 + 18 + 19 = \mathbf{70}$
* **计算结果**：`tensor([6., 22., 38., 54., 70.])`
* **形状变化**：`[5, 4]` ➡️ 水平挤压 ➡️ `[5]`（第 1 维的“4”被挤平消除，输出长度为 5 的一维向量）。

## 3. 终极不迷路法则：【消消乐法则】

遇到任意高维张量的降维运算，不需要在脑海中吃力地画立体空间图，直接使用 **`shape` 消消乐法则**：

> **“指定哪个 `axis`，就直接把对应索引位置上的数字给擦掉！”**

* **例 1（二维）**：`shape = [5, 4]`
  * `axis=0` ➡️ 擦掉第 0 位的数字 $5$ ➡️ 输出形状为 `[4]`
  * `axis=1` ➡️ 擦掉第 1 位的数字 $4$ ➡️ 输出形状为 `[5]`

* **例 2（三维，打破“变一维”的误区）**：`shape = [2, 3, 4]`
  * `axis=1` ➡️ 擦掉中间第 1 位的数字 $3$ ➡️ 输出形状为 `[2, 4]`（**依然保持二维，绝非变成一维！**）

## 4. 关键参数进阶：`keepdims=True`（保留维度）

在神经网络中（例如计算 Softmax、归一化、均值），经常需要利用广播机制让原张量除以求和结果。此时若维度直接“消失”，会导致形状不匹配发生广播报错。

```python
A = torch.arange(20, dtype=torch.float32).reshape(5, 4)

# 默认情况下（维数消失，从 2 维降到 1 维）
sum_default = A.sum(axis=1)               # shape 为 torch.Size([5])

# 开启 keepdims=True（保留轴，长度变为 1，依然保持 2 维）
sum_keep = A.sum(axis=1, keepdims=True)   # shape 为 torch.Size([5, 1])

# 妙用：A / sum_keep 可以直接触发广播机制，逐行完成归一化！
norm_A = A / sum_keep
```
