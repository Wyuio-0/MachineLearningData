## 1. Pandas 数据提取：`data.iloc[:, 0:2]` 深度拆解

在数据预处理阶段，我们经常需要将原始表格数据拆解为**“输入特征（Features, $X$）”**和**“预测目标（Labels, $y$）”**。

### 1.1 语法规则：`data.iloc[行切片, 列切片]`
* **逗号 `,` 是分水岭**：逗号左边控制**行**，逗号右边控制**列**。
* **左侧 `:`（行选择）**：单独一个冒号代表**“全选”**，即提取所有样本行（从第 0 行到最后一行）。
* **右侧 `0:2`（列选择）**：遵循 Python 标准切片的**“左闭右开”**原则，提取**第 0 列和第 1 列**（共 2 列），不包含索引为 2 的那一列。

### 1.2 经典特征与标签分离范式
假设数据表包含房间数、巷子类型及房价：
```python
# 1. 取出前两列特征（房间数、巷子类型），作为模型输入 X
inputs = data.iloc[:, 0:2]

# 2. 取出最后一列（售价），作为模型预测目标 y
outputs = data.iloc[:, 2]
```

## 2. 张量降维求和：`A.sum(axis=...)` 到底是怎么算的？

很多初学者容易被教材中的“输入轴 $k$ 的维数在输出形状中消失”绕晕。其实本质非常直观：**指定哪个轴，就是顺着哪个物理方向把数据压扁合并！**

### 2.1 案例矩阵 $A$（5 行 4 列）
假设矩阵 $A = \text{arange}(20).\text{reshape}(5, 4)$，其内部真实数字分布如下：

```text
               第0列   第1列   第2列   第3列
    第 0 行: [   0,      1,      2,      3   ]
    第 1 行: [   4,      5,      6,      7   ]
    第 2 行: [   8,      9,     10,     11   ]
    第 3 行: [  12,     13,     14,     15   ]
    第 4 行: [  16,     17,     18,     19   ]
```
* **原形状**：`shape = [5, 4]`
* **轴 0（axis=0）**：垂直向下的方向（跨越 5 行）
* **轴 1（axis=1）**：水平向右的方向（跨越 4 列）

---

### 2.2 `A.sum(axis=0)`：千斤顶自上而下压扁（列求和）

* **计算方式**：顺着垂直向下的方向，将每一列内部的 5 个数字纵向相加：
  * 第 0 列：$0 + 4 + 8 + 12 + 16 = \mathbf{40}$
  * 第 1 列：$1 + 5 + 9 + 13 + 17 = \mathbf{45}$
  * 第 2 列：$2 + 6 + 10 + 14 + 18 = \mathbf{50}$
  * 第 3 列：$3 + 7 + 11 + 15 + 19 = \mathbf{55}$
* **计算结果**：`tensor([40., 45., 50., 55.])`
* **形状变化**：`[5, 4]` ➡️ 垂直压扁 ➡️ `[4]`（第 0 维的“5”被压平消除，输出长度为 4 的一维向量）。

---

### 2.3 `A.sum(axis=1)`：推土机自左往右推平（行求和）

* **计算方式**：顺着水平向右的方向，将每一行内部的 4 个数字横向相加：
  * 第 0 行：$0 + 1 + 2 + 3 = \mathbf{6}$
  * 第 1 行：$4 + 5 + 6 + 7 = \mathbf{22}$
  * 第 2 行：$8 + 9 + 10 + 11 = \mathbf{38}$
  * 第 3 行：$12 + 13 + 14 + 15 = \mathbf{54}$
  * 第 4 行：$16 + 17 + 18 + 19 = \mathbf{70}$
* **计算结果**：`tensor([6., 22., 38., 54., 70.])`
* **形状变化**：`[5, 4]` ➡️ 水平挤压 ➡️ `[5]`（第 1 维的“4”被挤平消除，输出长度为 5 的一维向量）。

## 3. 终极不迷路法则：【消消乐法则】

遇到任意高维张量的降维运算，不需要在脑海中吃力地画立体空间图，直接使用 **`shape` 消消乐法则**：

> **“指定哪个 `axis`，就直接把对应索引位置上的数字给擦掉！”**

* **例 1（二维）**：`shape = [5, 4]`
  * `axis=0` ➡️ 擦掉第 0 位的数字 $5$ ➡️ 输出形状为 `[4]`
  * `axis=1` ➡️ 擦掉第 1 位的数字 $4$ ➡️ 输出形状为 `[5]`

* **例 2（三维，打破“变一维”的误区）**：`shape = [2, 3, 4]`
  * `axis=1` ➡️ 擦掉中间第 1 位的数字 $3$ ➡️ 输出形状为 `[2, 4]`（**依然保持二维，绝非变成一维！**）

## 4. 关键参数进阶：`keepdims=True`（保留维度）

在神经网络中（例如计算 Softmax、归一化、均值），经常需要利用广播机制让原张量除以求和结果。此时若维度直接“消失”，会导致形状不匹配发生广播报错。

```python
A = torch.arange(20, dtype=torch.float32).reshape(5, 4)

# 默认情况下（维数消失，从 2 维降到 1 维）
sum_default = A.sum(axis=1)               # shape 为 torch.Size([5])

# 开启 keepdims=True（保留轴，长度变为 1，依然保持 2 维）
sum_keep = A.sum(axis=1, keepdims=True)   # shape 为 torch.Size([5, 1])

# 妙用：A / sum_keep 可以直接触发广播机制，逐行完成归一化！
norm_A = A / sum_keep                      # shape 依然为 (5, 4)
```

## 5. 点积（Dot Product）全景剖析

### 5.1 代数定义与手算逻辑
对于两个长度相同的一维向量 $\mathbf{x}, \mathbf{y} \in \mathbb{R}^d$，点积是**对应位置元素相乘，然后全部相加**，输出为一个**标量**：
$$
\mathbf{x}^\top \mathbf{y} = \langle \mathbf{x}, \mathbf{y} \rangle = \sum_{i=1}^d x_i y_i = x_1 y_1 + x_2 y_2 + \cdots + x_d y_d
$$

*示例*：
$\mathbf{x} = [1.0, 2.0, 3.0, 4.0]$，$\mathbf{y} = [2.0, 0.0, 1.0, 3.0]$
点积结果：$1\times 2 + 2\times 0 + 3\times 1 + 4\times 3 = 2 + 0 + 3 + 12 = 17.0$。

### 5.2 几何意义：投影与相似度
$$
\mathbf{x} \cdot \mathbf{y} = \|\mathbf{x}\| \|\mathbf{y}\| \cos(\theta)
$$
* **物理直觉**：等于向量 $\mathbf{x}$ 在向量 $\mathbf{y}$ 方向上的**投影长度**乘以 $\mathbf{y}$ 的自身长度。
* **方向相似度判定**：
  * **点积 $> 0$**（锐角 $\theta < 90^\circ$）：两向量方向大体相同，夹角越小点积越大。
  * **点积 $= 0$**（直角 $\theta = 90^\circ$）：两向量**正交（垂直）**，彼此完全无关/独立。
  * **点积 $< 0$**（钝角 $\theta > 90^\circ$）：两向量方向相反。

### 5.3 PyTorch 实现的三种方式
```python
import torch

x = torch.tensor([1.0, 2.0, 3.0, 4.0])
y = torch.tensor([2.0, 0.0, 1.0, 3.0])

# 方式 1：标准函数（仅限 1D 向量）
torch.dot(x, y)          # tensor(17.)

# 方式 2：按元素相乘再求和（D2L 教材等价推导）
torch.sum(x * y)         # tensor(17.)

# 方式 3：@ 矩阵乘法运算符（1D 向量时自动退化为点积）
x @ y                    # tensor(17.)
```

### 5.4 深度学习应用场景
1. **全连接层神经元前向计算**：$\mathbf{w}^\top \mathbf{x} + b$ 是特征与权重的点积。
2. **Transformer 自注意力打分（Attention Score）**：$Q K^\top$ 本质就是大量的向量点积，用来评估词与词之间的关联度。

## 6. 矩阵乘法 vs Hadamard 积（按元素乘法）核心辨析

在日常表达中，“矩阵乘法”绝不能与“Hadamard 积”混为一谈，二者的数学逻辑、形状要求与运算规则截然不同：

| 对比维度 | **Hadamard 积 (按元素相乘)** | **矩阵乘法 (Matrix Multiplication)** |
| :--- | :--- | :--- |
| **数学记号** | $A \odot B$ | $A B$ 或 $A \times B$ |
| **PyTorch 语法** | `A * B` | `A @ B` 或 `torch.mm(A, B)` |
| **形状要求** | 两个矩阵形状必须**完全相同**（如 $3 \times 4$ 乘 $3 \times 4$） | **左矩阵列数必须等于右矩阵行数**（如 $n \times k$ 乘 $k \times m$） |
| **运算规则** | **各乘各的**：$C_{ij} = A_{ij} \times B_{ij}$ | **行点乘列，先乘后加**：$C_{ij} = \sum_{p=1}^k A_{ip} B_{pj}$ |
| **输出形状** | 形状保持不变：$(3, 4)$ | 中间维度 $k$ 消除，输出形状为 $(n, m)$ |
| **物理/几何直觉** | 特征掩码、打折加权（逐位置调节） | 坐标空间线性变换 / 神经网络全连接映射 |

> **一句话记忆口诀**：
> - `*` 是“各回各家，各乘各的”，原样大小。
> - `@` 是“左行乘右列，先乘再相加”，降维拼接。

## 7. 范数（Norm）：向量与矩阵的“测量尺”

### 7.1 概念本质
范数是将向量映射为一个非负实数（标量）的函数 $f(\mathbf{x})$，用来衡量向量“**有多大/有多长**”。
> **注意**：这里的大小**不代表维数多少**，而是代表向量内部各分量汇聚而成的**整体能量/长度**。

### 7.2 判定准则（范数的三大性质）
1. **等比例缩放（绝对齐次性）**：$f(\alpha \mathbf{x}) = |\alpha| f(\mathbf{x})$
2. **三角不等式（两边之和大于第三边）**：$f(\mathbf{x} + \mathbf{y}) \le f(\mathbf{x}) + f(\mathbf{y})$
3. **非负性与正定性**：$f(\mathbf{x}) \ge 0$，且**当且仅当** $\mathbf{x} = \mathbf{0}$ 时才有 $f(\mathbf{x}) = 0$。

### 7.3 深度学习三大常用范数
1. **$L_2$ 范数（欧几里得距离，模长）**：
   $$
   \|\mathbf{x}\|_2 = \sqrt{\sum_{i=1}^n x_i^2}
   $$
   * 平时省略下标的 $\|\mathbf{x}\|$ 默认指 $L_2$ 范数。
   * PyTorch 代码：`torch.norm(u)`。
2. **$L_1$ 范数（曼哈顿距离，街区距离）**：
   $$
   \|\mathbf{x}\|_1 = \sum_{i=1}^n |x_i|
   $$
   * 元素绝对值之和，不受极端大值平方放大的影响，抗噪性强；常用在 Lasso 正则化中诱导稀疏解（让不重要的权重直接为 0）。
   * PyTorch 代码：`torch.abs(u).sum()`。
3. **Frobenius 范数（矩阵的 $L_2$ 范数）**：
   $$
   \|X\|_F = \sqrt{\sum_{i=1}^m \sum_{j=1}^n x_{ij}^2}
   $$
   * 通俗理解：**把矩阵拍平成一维长向量，然后求它的 $L_2$ 范数**。
   * PyTorch 代码：`torch.norm(torch.ones((4, 9)))`（$4\times 9=36$ 个 1，开方为 6）。

### 7.4 为什么深度学习离不开范数？
* **衡量模型预测误差（Loss Function）**：MSE 损失本质是误差向量的 $L_2$ 范数平方；MAE 损失是误差向量的 $L_1$ 范数。优化过程就是使该范数最小化。
* **防止模型过拟合（Weight Decay 权重衰减）**：在损失函数中增加惩罚项 $\lambda \|\mathbf{w}\|_2^2$（$L_2$ 正则化），限制模型参数过大，提升泛化性能。

## 8. 张量 `len(X)` 的底层机制与习题问答

### 8.1 经典思考题
> **问**：对于形状为 `(2, 3, 4)` 的张量 $X$，`len(X)` 输出什么？为什么等于 2？

### 8.2 核心机制揭秘
1. **Python 最外层容器本质（俄罗斯套娃模型）**：
   高维张量在 Python 视角下属于多层嵌套结构：
   - 形状为 `(2, 3, 4)` 的张量，最外层包含 **2 个子元素**（每个子元素是一个 $3 \times 4$ 矩阵）；
   - Python 内置的 `len()` 函数遵循“只探查最外层”的原则，因此直接返回 `2`。
2. **轴 0 绑定定律**：
   **对于任意维度的张量 $X$，`len(X)` 总是且仅等于它的第 0 个轴（axis=0）的长度，即 `X.shape[0]`。**
   - 矩阵 `(5, 4)` $\implies len = 5$
   - 3阶张量 `(2, 3, 4)` $\implies len = 2$
   - 图像批次 `(128, 3, 224, 224)` $\implies len = 128$

### 8.3 属性速查辨析表
| 函数/属性 | 形状 `(2, 3, 4)` 的结果 | 作用与含义 |
| :--- | :--- | :--- |
| `len(X)` | `2` | 最外层容器长度（仅看 `axis=0`，在深度学习中常代表 Batch Size） |
| `X.shape` | `torch.Size([2, 3, 4])` | 全局各维度尺寸全景图 |
| `X.numel()` | `24` | 内部具体数值元素的绝对总数（$2 \times 3 \times 4 = 24$） |
