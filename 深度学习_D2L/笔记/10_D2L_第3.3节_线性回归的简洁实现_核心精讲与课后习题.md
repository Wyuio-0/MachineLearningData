## 一、从“手工造轮子”到“工业级流水线”

在 3.2 节中，我们手动编写了：
1. `data_iter`（基于切片与索引随机打乱） $\to$ **3.3 节升级为：`TensorDataset` + `DataLoader`**（多线程、内存映射预加载、自动批处理）；
2. `linreg`（手动 `torch.matmul(X, w) + b`） $\to$ **3.3 节升级为：`nn.Sequential` + `nn.Linear`**（高度优化的 C++ / CUDA 底层算子与参数自动化管理）；

4. `sgd`（手动 `param -= lr * grad / batch_size` 和 `param.grad.zero_()`） $\to$ **3.3 节升级为：`torch.optim.SGD`**（一键 `step()` 与 `zero_grad()`）。

## 二、四大工业级核心组件剖析

### 2.1 组件一：数据管道 —— `TensorDataset` 与 `DataLoader`
```python
from torch.utils import data

def load_array(data_arrays, batch_size, is_train=True):
    """构造一个PyTorch数据迭代器"""
    dataset = data.TensorDataset(*data_arrays)
    return data.DataLoader(dataset, batch_size, shuffle=is_train)
```
* **`TensorDataset`**：将输入的特征张量和标签张量按第一维度一对一打包成数据元组。
* **`DataLoader`**：
  * `shuffle=True`：在每个 Epoch 开始时自动洗牌（打乱顺序）；
  * `batch_size`：自动分批切片，支持并行加速加载；
  * 支持在后续扩展多进程工作线程（`num_workers`）和自动丢弃残缺批次（`drop_last`）。
* **读取首批验证**：
  ```python
  next(iter(data_iter))  # 使用 Python 内置迭代器访问首个小批量
  ```

### 2.2 组件二：神经网络架构容器 —— `nn.Sequential` 与 `nn.Linear`
```python
from torch import nn

net = nn.Sequential(nn.Linear(2, 1))
```
* **`nn.Linear(in_features, out_features)`**：
  * 全连接层（Dense / Fully-Connected Layer）；
  * 自动在内部注册两个可训练参数：权重张量 `weight`（形状为 `(out_features, in_features)` 即 `(1, 2)`）与偏置向量 `bias`（形状为 `(out_features,)` 即 `(1,)`）；
  * 前向计算等价于 $\mathbf{y} = \mathbf{x} \mathbf{W}^\top + \mathbf{b}$。
* **`nn.Sequential`**：
  * 层的有序容器（Sequence Container）；
  * 输入数据传入第一层后，其输出自动作为第二层的输入，依此类推。虽然当前只有单层，但使用 `Sequential` 能与后续深层网络保持标准工业架构统一。

### 2.3 组件三：参数就地初始化与方法
```python
net[0].weight.data.normal_(0, 0.01)
net[0].bias.data.fill_(0)
```
* **`net[0]`**：通过索引访问 `Sequential` 容器中的第 0 层（即 `nn.Linear`）；
* **`.weight.data` 与 `.bias.data`**：直接穿透到底层张量数据，不触发计算图记录；
* **下划线就地操作（In-place）**：
  * `normal_(mean, std)`：将张量当前内存直接覆盖为正态分布随机数；
  * `fill_(val)`：将张量当前内存全部填充为指定常数。

### 2.4 组件四：损失函数与优化器
* **均方误差损失**：
  ```python
  loss = nn.MSELoss()  # 默认 reduction='mean'，自动计算整批样本损失的均值
  ```
* **优化器配置**：
  ```python
  trainer = torch.optim.SGD(net.parameters(), lr=0.03)
  ```

### 2.5 组件五：标准化生产级训练循环
```python
num_epochs = 3
for epoch in range(num_epochs):
    for X, y in data_iter:
        l = loss(net(X), y)     # 1. 前向传播：模型预测 + 计算均值损失
        trainer.zero_grad()      # 2. 优化器梯度清零
        l.backward()             # 3. 反向传播：自动微分计算梯度
        trainer.step()           # 4. 优化器单步更新参数
    
    with torch.no_grad():
        l = loss(net(features), labels)
        print(f'epoch {epoch + 1}, loss {l:f}')
```

> 
> | 步骤 | 3.2 从零开始（手工） | 3.3 简洁实现（框架） |
> | :--- | :--- | :--- |
> | **数据加载** | 手写 `random.shuffle` 与 `yield` | `data.DataLoader(dataset, batch_size)` |
> | **网络定义** | 手写 `def linreg(X, w, b)` | `net = nn.Sequential(nn.Linear(2, 1))` |

## 三、课后习题深度精解（全 3 题）

### 练习 1：如果将小批量的总损失替换为小批量损失的平均值，需要如何更改学习率？

#### 1. 数学推导与等价性分析
* 在 3.2 节中，我们计算的是**总损失**：
  $$L_{\text{sum}} = \sum_{i \in \mathcal{B}} \frac{1}{2} (\hat{y}^{(i)} - y^{(i)})^2$$
  对应的梯度为 $G_{\text{sum}} = \sum_{i \in \mathcal{B}} g^{(i)}$。
  在手写的 `sgd` 函数中，我们更新参数时除以了 `batch_size`：
  $$\mathbf{w} \leftarrow \mathbf{w} - \eta_{\text{sum}} \cdot \frac{G_{\text{sum}}}{|\mathcal{B}|} = \mathbf{w} - \eta_{\text{sum}} \cdot \bar{G}$$
* 如果在计算损失时就直接除以了批量大小，计算的是**平均损失**：
  $$L_{\text{mean}} = \frac{1}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \frac{1}{2} (\hat{y}^{(i)} - y^{(i)})^2$$
  对应的梯度直接就是**平均梯度**：
  $$G_{\text{mean}} = \nabla L_{\text{mean}} = \frac{1}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} g^{(i)} = \bar{G}$$
* **结论**：
  1. **如果优化器没有除以 `batch_size`（直接执行 $\mathbf{w} \leftarrow \mathbf{w} - \eta \cdot G$）**：
     由于 $G_{\text{mean}} = \frac{1}{|\mathcal{B}|} G_{\text{sum}}$，要想保持参数更新步长完全一致，**学习率必须放大 $|\mathcal{B}|$ 倍**（即 $\eta_{\text{new}} = \eta \times |\mathcal{B}|$）；
  2. **在 3.3 节的实际 PyTorch 框架中**：
     `nn.MSELoss()` 默认是 `reduction='mean'`（算均值），而 `torch.optim.SGD` 执行的是 `param -= lr * param.grad`（不额外除以 batch_size）。这使得传入的 `lr=0.03` 刚好直接作用在平均梯度上，与 3.2 节中手写除以 `batch_size` 后的等效学习率**完全一致，因此无需更改学习率！**

### 练习 2：查看深度学习框架文档，提供了哪些损失函数和初始化方法？用 Huber 损失代替原损失。

#### 1. PyTorch 常用损失函数库（`torch.nn`）
* **回归问题**：
  * `nn.MSELoss`：均方误差（L2 损失），对大离群点敏感；
  * `nn.L1Loss`：平均绝对误差（L1 损失），对离群点鲁棒但驻点不可导；
  * `nn.SmoothL1Loss` / `nn.HuberLoss`：结合 L1 与 L2 优点的平滑损失。
* **分类问题**：
  * `nn.CrossEntropyLoss`：交叉熵损失（包含 Softmax + NLLLoss）；
  * `nn.BCEWithLogitsLoss`：二分类交叉熵；
  * `nn.NLLLoss`：负对数似然损失。

#### 2. PyTorch 常用参数初始化方法库（`torch.nn.init`）
* `init.normal_(tensor, mean=0, std=1)`：高斯正态分布初始化；
* `init.constant_(tensor, val)` / `init.zeros_`：常数/零初始化；
* `init.uniform_(tensor, a=0, b=1)`：均匀分布初始化；
* `init.xavier_uniform_` / `init.xavier_normal_`：Glorot/Xavier 初始化（适合 Tanh/Sigmoid 激活的深层网络）；
* `init.kaiming_uniform_` / `init.kaiming_normal_`：He/Kaiming 初始化（适合 ReLU 激活的卷积与深度网络）。

#### 3. Huber 损失函数原理与代码实现
* **数学形式**：
  $$l_\sigma(y, \hat{y}) = \begin{cases} \frac{1}{2\sigma} (\hat{y} - y)^2, & \text{若 } |\hat{y} - y| \le \sigma \\ |\hat{y} - y| - \frac{\sigma}{2}, & \text{若 } |\hat{y} - y| > \sigma \end{cases}$$
* **优势**：在误差小处保持平滑二次可微性（避免震荡），在误差大处保持线性增长（抗离群异常值拉扯）。
* **代码实现替换**：
  ```python
  # 使用官方自带的 HuberLoss (设置 delta=0.01)
  loss_huber = nn.HuberLoss(delta=0.01)
  
  # 或使用原生 PyTorch 函数自定义实现:
  def custom_huber(y_hat, y, sigma=0.01):
      diff = torch.abs(y_hat - y)
      huber_l = torch.where(diff <= sigma, 0.5 * (diff ** 2) / sigma, diff - 0.5 * sigma)
      return huber_l.mean()
  ```

### 练习 3：如何访问线性回归模型的梯度？

#### 1. 访问方法与属性路径
在 PyTorch 中，线性回归模型的参数存储在对应的层对象中：
1. **访问权重参数的梯度**：
   ```python
   # 方式一：通过层索引访问
   w_grad = net[0].weight.grad
   
   # 方式二：通过遍历网络可学习参数列表访问
   for param in net.parameters():
       print(param.grad)
   ```
2. **访问偏置参数的梯度**：
   ```python
   b_grad = net[0].bias.grad
   ```
* **生命周期关键点**：
  * 在刚定义模型或调用 `trainer.zero_grad()` 后，`param.grad` 的值为 `None` 或全 0；
  * 只有在执行了 `l.backward()` 之后，计算图的反向传播才会将当前小批量的梯度填充到 `.grad` 属性中；
  * 如果在训练完后打印查看，即可直接提取出当前最终批次的数值梯度。
