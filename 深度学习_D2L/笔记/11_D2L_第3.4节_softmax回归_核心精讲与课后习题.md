## 一、分类问题与独热编码（One-Hot Encoding）

在回归任务中，输出是一个连续的标量（如房价 $y \in \mathbb{R}$）。而在分类任务中，输出是离散的类别标签（如 $y \in \{\text{猫}, \text{狗}, \text{鸡}\}$）。
* **为什么不能直接用标量 $1, 2, 3$ 标注类别？**
  如果标注 $\text{猫}=1, \text{狗}=2, \text{鸡}=3$，模型在优化时会隐含一个**错误的强序数假设**——即“鸡与猫的差距是狗与猫的 2 倍”，或者“狗是猫和鸡的平均值”。除年龄、评级等天然有序类别外，大部分离散类别之间不存在这种线性数值关系。
* **独热编码（One-Hot）**：
  若类别总数为 $q$，每个样本的标签表示为一个长度为 $q$ 的布尔向量 $\mathbf{y} \in \{0, 1\}^q$。该向量在实际类别对应的索引处为 $1$，其余全为 $0$：
  $$y \in \{ (1, 0, 0), (0, 1, 0), (0, 0, 1) \}$$

## 二、网络架构与 Softmax 归一化指数运算

### 2.1 网络架构与全连接参数开销
* 设输入特征为 $\mathbf{x} \in \mathbb{R}^d$，分类类别数为 $q$。
* softmax 回归依然属于**单层神经网络**，但具有多个输出：
  $$o_1 = \mathbf{x}^\top \mathbf{w}_1 + b_1, \quad o_2 = \mathbf{x}^\top \mathbf{w}_2 + b_2, \quad \dots, \quad o_q = \mathbf{x}^\top \mathbf{w}_q + b_q$$
* **参数矩阵规模**：权重矩阵 $\mathbf{W} \in \mathbb{R}^{d \times q}$，偏置向量 $\mathbf{b} \in \mathbb{R}^{1 \times q}$。参数量为 $\mathcal{O}(d \cdot q)$。

---

### 2.2 Softmax 运算机制
直接输出的末分（Logits）$o_j$ 是没有约束的实数（可能为负数、可能大于 1，且总和不为 1），无法直接作为概率使用。
为了将其规范化为一个有效的概率分布 $\hat{\mathbf{y}}$，社会科学家邓肯·卢斯（Duncan Luce）在选择模型中提出了 **Softmax 函数**：
$$\hat{y}_j = \text{softmax}(\mathbf{o})_j = \frac{\exp(o_j)}{\sum_{k=1}^q \exp(o_k)}$$

#### Softmax 三大核心数学特质：
1. **非负性保证**：指数函数 $\exp(u) > 0$，彻底消灭负数；
2. **规范性保证**：分母除以全部分子的总和，保证所有类别的预测概率之和严格等于 1：
   $$\sum_{j=1}^q \hat{y}_j = \frac{\sum_{j=1}^q \exp(o_j)}{\sum_{k=1}^q \exp(o_k)} = 1$$
3. **保持单调序（Argmax 保序性）**：
   因为指数函数严格单调递增，如果未规范化得分 $o_a > o_b$，则必然有 $\hat{y}_a > \hat{y}_b$。这意味着在推理做预测时，求最终类别无需计算昂贵的指数，直接取原始得分最大的类别即可：
   $$\operatorname*{argmax}_j \hat{y}_j = \operatorname*{argmax}_j o_j$$

## 三、交叉熵损失（Cross-Entropy Loss）与导数的数学之美

### 3.1 交叉熵损失构建（从极大似然估计推导）
假设样本标签由条件概率 $P(y \mid \mathbf{x})$ 给出。根据极大似然原理，我们希望最大化全部样本真实类别预测概率的联合似然：
$$P(\mathbf{Y} \mid \mathbf{X}) = \prod_{i=1}^n \prod_{j=1}^q \left(\hat{y}_j^{(i)}\right)^{y_j^{(i)}}$$
取负对数似然（Negative Log-Likelihood, NLL），得到单个样本的**交叉熵损失**：
$$l(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_{j=1}^q y_j \log \hat{y}_j$$
由于真实标签 $\mathbf{y}$ 是独热向量，假设样本的真实标签类别索引为 $c$（即 $y_c = 1$，其余 $y_j = 0$），则损失函数极简为：
$$l(\mathbf{y}, \hat{\mathbf{y}}) = -\log \hat{y}_c$$
* **直观含义**：模型只需要尽全力把真实正确类别 $c$ 对应的预测概率 $\hat{y}_c$ 往 $1$ 推！当 $\hat{y}_c \to 1$ 时，$-\log 1 = 0$（损失达到完美最小值）。

---

### 3.2 Softmax 结合交叉熵的导数之美
将 Softmax 定义代入交叉熵损失展开：
$$l(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_{j=1}^q y_j \log \left(\frac{\exp(o_j)}{\sum_{k=1}^q \exp(o_k)}\right) = \log\left(\sum_{k=1}^q \exp(o_k)\right) - \sum_{j=1}^q y_j o_j$$
对未规范化的第 $j$ 个输出得分 $o_j$ 求偏导：
$$\frac{\partial l}{\partial o_j} = \frac{\frac{\partial}{\partial o_j}\left(\sum_{k=1}^q \exp(o_k)\right)}{\sum_{k=1}^q \exp(o_k)} - y_j = \frac{\exp(o_j)}{\sum_{k=1}^q \exp(o_k)} - y_j = \mathbf{\hat{y}_j - y_j}$$

> **数学之美与物理直觉**：
> 交叉熵对未规范化预测得分 $o_j$ 的导数，竟然**奇迹般地退化成了模型预测概率与真实标签之间的简单残差 $(\hat{y}_j - y_j)$**！
> 这与线性回归中平方损失的导数 $(\hat{y} - y)$ 在形式上完全同构。这不是偶然，而是**所有指数族分布（Exponential Family）模型在自然参数化下的普遍优美性质**！

## 四、信息论基础：从惊异度到交叉熵

1. **信息量（Information Content / Surprise）**：
   香农将观察到事件 $j$ 的“惊异程度”量化为自信息：
   $$I(j) = -\log P(j)$$
   * 概率越低的事件发生（如“太阳从西边出来”），给人带来的信息量/惊异度越大；必然事件（$P=1$）发生带来的信息量为 0。
2. **香农熵（Shannon Entropy）**：
   真实数据生成分布 $P$ 的平均信息量期望，衡量系统的不可预测性/混乱度：
   $$H[P] = \mathbb{E}_{j \sim P}[-\log P(j)] = -\sum_j P(j) \log P(j)$$
3. **相对熵（KL 散度 Kullback-Leibler Divergence）**：
   衡量用主观模型分布 $Q$ 去近似真实分布 $P$ 所产生的额外信息损失：
   $$D_{\text{KL}}(P \parallel Q) = \sum_j P(j) \log \frac{P(j)}{Q(j)} \ge 0$$
4. **交叉熵（Cross-Entropy）**：
   $$H(P, Q) = H[P] + D_{\text{KL}}(P \parallel Q) = -\sum_j P(j) \log Q(j)$$
   * 因为真实标签分布 $P$ 是客观给定的（其熵 $H[P]$ 是固定常数），**最小化交叉熵 $H(P, Q)$ 在数学上完全等价于最小化预测分布 $Q$ 与真实分布 $P$ 之间的 KL 散度！**

## 五、课后习题深度精解（全 3 题）

### 练习 1：指数族、二阶导数与方差匹配

#### 1. 计算 Softmax 交叉熵损失 $l(\mathbf{y}, \hat{\mathbf{y}})$ 的二阶导数（海森矩阵）
已知一阶导数（梯度）为：
$$\frac{\partial l}{\partial o_i} = \hat{y}_i - y_i, \quad \text{其中 } \hat{y}_i = \frac{\exp(o_i)}{\sum_{k} \exp(o_k)}$$
进一步对 $o_j$ 求二阶偏导 $\frac{\partial^2 l}{\partial o_i \partial o_j}$：
* **当 $i = j$ 时（对角线元素）**：
  $$\frac{\partial \hat{y}_i}{\partial o_i} = \frac{\exp(o_i)\sum_k \exp(o_k) - \exp(o_i)\exp(o_i)}{\left(\sum_k \exp(o_k)\right)^2} = \hat{y}_i(1 - \hat{y}_i)$$
* **当 $i \ne j$ 时（非对角线元素）**：
  $$\frac{\partial \hat{y}_i}{\partial o_j} = \frac{0 - \exp(o_i)\exp(o_j)}{\left(\sum_k \exp(o_k)\right)^2} = -\hat{y}_i \hat{y}_j$$
* **综合矩阵形式（Hessian 矩阵）**：
  $$\mathbf{H}_{ij} = \frac{\partial^2 l}{\partial o_i \partial o_j} = \hat{y}_i \delta_{ij} - \hat{y}_i \hat{y}_j$$
  其中 $\delta_{ij}$ 为克罗内克尔符号（$i=j$ 时为 1，否则为 0）。即：
  $$\mathbf{H} = \operatorname{diag}(\hat{\mathbf{y}}) - \hat{\mathbf{y}} \hat{\mathbf{y}}^\top$$

#### 2. 计算 $\text{softmax}(\mathbf{o})$ 多项分布的协方差矩阵并匹配
设随机向量 $\mathbf{Z} \sim \text{Categorical}(\hat{\mathbf{y}})$ 是单次抽样产生的独热向量，满足：
$$P(\mathbf{Z} = \mathbf{e}_i) = \hat{y}_i, \quad \mathbb{E}[Z_i] = \hat{y}_i$$
其协方差矩阵为：
$$\operatorname{Cov}(Z_i, Z_j) = \mathbb{E}[Z_i Z_j] - \mathbb{E}[Z_i]\mathbb{E}[Z_j]$$
* 当 $i = j$ 时：$Z_i^2 = Z_i$，故 $\mathbb{E}[Z_i^2] = \hat{y}_i$，方差为 $\hat{y}_i - \hat{y}_i^2 = \hat{y}_i(1 - \hat{y}_i)$；
* 当 $i \ne j$ 时：独热向量不可能有两个分量同时为 1，故 $Z_i Z_j = 0$，$\mathbb{E}[Z_i Z_j] = 0$，协方差为 $-\hat{y}_i \hat{y}_j$。
* **结论**：
  $$\operatorname{Cov}(\mathbf{Z}) = \operatorname{diag}(\hat{\mathbf{y}}) - \hat{\mathbf{y}} \hat{\mathbf{y}}^\top = \mathbf{H}$$
  **交叉熵损失关于输入 Logits 的二阶导数矩阵（海森矩阵），在数学上精确等于多项分布本身的协方差矩阵！**

### 练习 2：等概率三类别编码问题与联合编码优化

#### 1. 直接为三个等概率类 $(1/3, 1/3, 1/3)$ 设计独立二进制代码的问题
* 三个类别的理论香农熵极限为：
  $$H = -\sum_{i=1}^3 \frac{1}{3} \log_2 \frac{1}{3} = \log_2 3 \approx 1.585 \text{ 比特}$$
* 若对单次观测进行独立二进制前缀编码：
  要区分 3 个符号，至少需要长度为 2 的编码（如 `00`, `01`, `10`），此时每个符号的平均码长为 **2 比特**。
* **问题**：平均码长 2 比特明显大于理论极限 1.585 比特，存在高达 $2 - 1.585 = 0.415$ 比特的严重冗余浪费（效率仅 $79.2\%$）。

#### 2. 联合编码设计与极限逼近（香农第一编码定理）
* **方案：联合块编码（Block Coding）**。每次将 $n$ 个独立观测样本打包联合编码。
  * **当 $n=2$ 时（两两联合编码）**：
    可能的结果有 $3^2 = 9$ 种状态。理论熵为 $2 \times \log_2 3 \approx 3.17$ 比特。
    我们可以用 3 位二进制表示前 7 种状态，4 位表示后 2 种状态（霍夫曼编码），平均码长为 $\frac{7}{9} \times 3 + \frac{2}{9} \times 4 = \frac{29}{9} \approx 3.22$ 比特。折合每个符号仅需 $\frac{3.22}{2} = 1.61$ 比特！
  * **当 $n \to \infty$ 时**：
    根据香农无失真信源编码定理，联合编码 $n$ 个符号所需码长 $L_n$ 满足：
    $$n H \le L_n < n H + 1 \implies H \le \frac{L_n}{n} < H + \frac{1}{n}$$
    当 $n$ 足够大时，单符号平均码长可以**无限逼近理论极限 $\log_2 3 \approx 1.585$ 比特**。

### 练习 3：真正的数学平滑最大值 $\text{RealSoftMax}$ 性质证明

定义真正的平滑最大值函数为：
$$\text{RealSoftMax}(a, b) = \log(\exp(a) + \exp(b))$$

#### 1. 证明 $\text{RealSoftMax}(a, b) > \max(a, b)$
* 不失一般性，设 $M = \max(a, b)$。
* 则 $\exp(a) > 0$ 且 $\exp(b) > 0$，故：
  $$\exp(a) + \exp(b) > \exp(\max(a, b))$$
* 对两边同时取严格单调递增的自然对数：
  $$\log(\exp(a) + \exp(b)) > \log(\exp(\max(a, b))) = \max(a, b)$$
* **证毕！**

#### 2. 证明 $\frac{1}{\lambda}\text{RealSoftMax}(\lambda a, \lambda b) > \max(a, b)$（$\lambda > 0$）
* 令 $a' = \lambda a, b' = \lambda b$。由第 1 问结论可知：
  $$\text{RealSoftMax}(\lambda a, \lambda b) > \max(\lambda a, \lambda b)$$
* 因为 $\lambda > 0$，有 $\max(\lambda a, \lambda b) = \lambda \max(a, b)$。两边同除以正数 $\lambda$：
  $$\frac{1}{\lambda}\text{RealSoftMax}(\lambda a, \lambda b) > \max(a, b)$$
* **证毕！**

#### 3. 证明当 $\lambda \to \infty$ 时极限趋近于 $\max(a, b)$
* 提取最大项 $M = \max(a, b)$：
  $$\exp(\lambda a) + \exp(\lambda b) = \exp(\lambda M) \left( \exp(\lambda(a - M)) + \exp(\lambda(b - M)) \right)$$
* 代入对数表达式：
  $$\frac{1}{\lambda}\log(\exp(\lambda a) + \exp(\lambda b)) = M + \frac{1}{\lambda}\log\left( \exp(\lambda(a - M)) + \exp(\lambda(b - M)) \right)$$
* 当 $\lambda \to \infty$ 时：
  由于 $a - M \le 0$ 且 $b - M \le 0$，括号内的非最大项指数趋于 0，最大项指数为 $\exp(0)=1$。
  因此项的和介于 $1$ 到 $2$ 之间，取对数后是一个有限常数 $[0, \log 2]$。
  当除以 $\lambda \to \infty$ 时，第二项趋于 0：
  $$\lim_{\lambda \to \infty} \frac{1}{\lambda}\text{RealSoftMax}(\lambda a, \lambda b) = M + 0 = \max(a, b)$$
* **证毕！**

#### 4. $\text{SoftMin}$ 的形式
* 利用 $\min(a, b) = -\max(-a, -b)$，平滑极小值定义为：
  $$\text{SoftMin}(a, b) = -\log(\exp(-a) + \exp(-b))$$

#### 5. 扩展到多个数字
对于任意向量 $\mathbf{x} = (x_1, x_2, \dots, x_n)$：
$$\text{RealSoftMax}(\mathbf{x}) = \log\left(\sum_{i=1}^n \exp(x_i)\right)$$
在凸优化和物理统计力学中，该函数也被称为 **Log-Sum-Exp（LSE）函数** 或自由能（Free Energy）。
