## 练习题 1：证明矩阵转置的转置是自身，即 $(A^\top)^\top = A$

### 1.1 数学证明
设矩阵 $A \in \mathbb{R}^{m \times n}$，其第 $i$ 行第 $j$ 列的元素记为 $a_{ij}$（其中 $1 \le i \le m, 1 \le j \le n$）。

1. 令矩阵 $B = A^\top \in \mathbb{R}^{n \times m}$。根据矩阵转置定义，交换行与列索引，其元素满足：
   $$b_{ji} = a_{ij}$$
2. 现在对矩阵 $B$ 再次求转置，令 $C = B^\top = (A^\top)^\top \in \mathbb{R}^{m \times n}$。同样由转置定义可得：
   $$c_{ij} = b_{ji}$$
3. 将 $b_{ji} = a_{ij}$ 代入，得到：
   $$c_{ij} = a_{ij} \quad (\forall i, j)$$

由于矩阵 $C$ 与矩阵 $A$ 的形状相同（均为 $m \times n$），且每一个对应位置的元素均严格相等，因此证得：
$$(A^\top)^\top = A \quad \blacksquare$$

### 1.2 PyTorch 代码验证
```python
import torch

A = torch.arange(12).reshape(3, 4)
assert torch.equal((A.T).T, A)
print("习题 1 验证通过: (A.T).T == A")
```

## 练习题 2：证明“转置的和”等于“和的转置”，即 $A^\top + B^\top = (A + B)^\top$

### 2.1 数学证明
设矩阵 $A, B \in \mathbb{R}^{m \times n}$，其对应位置元素分别为 $a_{ij}$ 与 $b_{ij}$。

1. **计算左式（转置的和）**：
   - 矩阵 $A^\top, B^\top \in \mathbb{R}^{n \times m}$，其第 $j$ 行第 $i$ 列的元素分别为 $(A^\top)_{ji} = a_{ij}$ 和 $(B^\top)_{ji} = b_{ij}$。
   - 二者按元素相加，得到新矩阵的第 $j$ 行第 $i$ 列元素：
     $$(A^\top + B^\top)_{ji} = (A^\top)_{ji} + (B^\top)_{ji} = a_{ij} + b_{ij}$$

2. **计算右式（和的转置）**：
   - 先计算矩阵和 $S = A + B \in \mathbb{R}^{m \times n}$，其第 $i$ 行第 $j$ 列元素为：
     $$s_{ij} = a_{ij} + b_{ij}$$
   - 再求转置 $S^\top = (A + B)^\top \in \mathbb{R}^{n \times m}$，其第 $j$ 行第 $i$ 列元素为：
     $$((A + B)^\top)_{ji} = s_{ij} = a_{ij} + b_{ij}$$

对比左式与右式，对于所有 $1 \le j \le n, 1 \le i \le m$，对应元素完全相同，形状一致。因此证得：
$$A^\top + B^\top = (A + B)^\top \quad \blacksquare$$

### 2.2 PyTorch 代码验证
```python
A = torch.randn(3, 4)
B = torch.randn(3, 4)
assert torch.allclose(A.T + B.T, (A + B).T)
print("习题 2 验证通过: A.T + B.T == (A + B).T")
```

## 练习题 3：给定任意方阵 $A$，$A + A^\top$ 总是对称的吗？为什么？

### 3.1 结论
**是的，对于任意实数方阵 $A$，$A + A^\top$ 必然是对称矩阵！**

### 3.2 严密数学证明
根据对称矩阵的数学定义：一个矩阵 $M$ 是对称矩阵的充分必要条件是 **$M^\top = M$**。

1. 设 $A \in \mathbb{R}^{n \times n}$ 是任意方阵，令矩阵 $M = A + A^\top$。
2. 对矩阵 $M$ 整体求转置：
   $$M^\top = (A + A^\top)^\top$$
3. 应用**习题 2 的性质**（加法的转置等于转置的加法）：
   $$(A + A^\top)^\top = A^\top + (A^\top)^\top$$
4. 应用**习题 1 的性质**（转置的转置等于自身）：
   $$A^\top + (A^\top)^\top = A^\top + A$$
5. 因为矩阵加法满足**交换律**（$A^\top + A = A + A^\top$）：
   $$A^\top + A = A + A^\top = M$$
6. 由此推导得出：
   $$M^\top = M$$

因此，$A + A^\top$ 必定是对称矩阵。$\blacksquare$

### 3.3 PyTorch 代码验证
```python
A = torch.randn(5, 5)  # 任意非对称随机方阵
M = A + A.T
assert torch.equal(M, M.T)
print("习题 3 验证通过: M == M.T 为 True，必然对称")
```

## 练习题 4：形状为 $(2, 3, 4)$ 的张量 $X$。`len(X)` 的输出结果是什么？

### 4.1 答案
`len(X)` 的输出结果是：**`2`**。

### 4.2 原因剖析
在 Python 内部，多维张量（Tensor）在逻辑上属于嵌套容器（List of Lists of Lists）：
- 形状为 `(2, 3, 4)` 的张量，最外层包含 **2 个子块**；
- 每个子块是一个 $3 \times 4$ 的二维矩阵；
- Python 内置的 `len(obj)` 语义是**“仅统计当前最外层容器包含的元素个数”**，它不会向深层去递归遍历元素，因此直接返回 `2`。

## 练习题 5：对于任意形状的张量 $X$，`len(X)` 是否总是对应于 $X$ 特定轴的长度？这个轴是什么？

### 5.1 答案
**是的，总是对应于第 0 个轴（`axis=0`）的长度。**

### 5.2 规律与公式
对于任意维度 $\ge 1$ 的张量 $X$：
$$\text{len}(X) == X.\text{shape}[0]$$

*示例对照*：
* 1维向量：`shape = (4,)` $\implies \text{len} = 4$
* 2维矩阵：`shape = (5, 4)` $\implies \text{len} = 5$（行数）
* 3维张量：`shape = (2, 3, 4)` $\implies \text{len} = 2$
* 4维图片批次：`shape = (64, 3, 224, 224)` $\implies \text{len} = 64$（即 **Batch Size 批大小**）

*(注：0 维标量无轴，调用 `len` 会抛出 TypeError)*。

## 练习题 6：运行 `A / A.sum(axis=1)`，看看会发生什么。请分析一下原因？

### 6.1 运行结果（报错）
执行后不会得到预期结果，而是会抛出如下 **RuntimeError**：
```text
RuntimeError: The size of tensor a (4) must match the size of tensor b (5) at non-singleton dimension 1
```

### 6.2 深入原因分析（PyTorch 广播机制对齐法则）
假设矩阵 $A$ 的形状为 `(5, 4)`：
1. **求和降维导致轴消失**：
   调用 `A.sum(axis=1)` 时，默认参数 `keepdims=False`。根据**消消乐法则**，轴 1 被压平消除，求和结果退化为一维向量，形状为 **`(5,)`**。
2. **广播从最右侧（末尾轴）对齐**：
   当尝试执行 `(5, 4) / (5,)` 时，PyTorch 按照通用广播规则从尾部轴向左对齐：
   ```text
   矩阵 A 形状:       5  ×  4
   sum_A 形状:              5
                           ↑
                       维度冲突！(4 与 5 不相等且均非 1)
   ```
   因为最右边的维度一个是 4，一个是 5，既不匹配也不包含长度为 1 的可广播轴，因此直接报错。

### 6.3 正确解决范式：`keepdims=True`
只要加上 `keepdims=True`，让消除的轴保留长度 1，形状变为 **`(5, 1)`**：
```python
sum_A = A.sum(axis=1, keepdims=True)  # shape 为 (5, 1)
result = A / sum_A                    # (5, 4) / (5, 1) 成功广播！
```
广播对齐情况：
```text
矩阵 A 形状:       5  ×  4
sum_A 形状:       5  ×  1
                      ↑
             长度为 1，自动复制 4 次完成广播除法！
```

## 练习题 7：考虑一个具有形状 $(2, 3, 4)$ 的张量，在轴 0、1、2 上的求和输出是什么形状？

### 7.1 解答（消消乐法则极速推导）
> **法则口诀**：指定求和的 `axis` 是几，就直接把形状元组中第几个位置的数字抹去！

原始形状：`(2, 3, 4)`，分别对应 `(axis=0, axis=1, axis=2)`。

1. **`X.sum(axis=0)`**：
   - 消除第 0 位（数字 2 消失）
   - **输出形状**：**`torch.Size([3, 4])`**
2. **`X.sum(axis=1)`**：
   - 消除第 1 位（数字 3 消失）
   - **输出形状**：**`torch.Size([2, 4])`**
3. **`X.sum(axis=2)`**：
   - 消除第 2 位（数字 4 消失）
   - **输出形状**：**`torch.Size([2, 3])`**

### 7.2 延伸：开启 `keepdims=True` 时的形状
- `X.sum(axis=0, keepdims=True)` $\implies$ `torch.Size([1, 3, 4])`
- `X.sum(axis=1, keepdims=True)` $\implies$ `torch.Size([2, 1, 4])`
- `X.sum(axis=2, keepdims=True)` $\implies$ `torch.Size([2, 3, 1])`

## 练习题 8：为 `linalg.norm` 提供 3 个或更多轴的张量，并观察其输出。对于任意形状的张量这个函数计算得到什么？

### 8.1 实验观察
```python
import torch

X = torch.arange(24, dtype=torch.float32).reshape(2, 3, 4)

# 调用 norm 函数
norm_val = torch.linalg.norm(X)
print("norm_val:", norm_val)              # tensor(65.7571)
print("norm_val.shape:", norm_val.shape)  # torch.Size([]) -> 零维标量
```

### 8.2 本质计算规则
对于任意高维多轴张量 $X$（无论是 3 维、4 维还是 $N$ 维），在**未指定特定 axis** 的情况下，`torch.linalg.norm(X)`（以及旧版 `torch.norm(X)`）计算的始终是：

> **全体元素平方和的平方根（即广义 Frobenius 范数 / 全局 $L_2$ 范数）**

数学公式表示为：
$$
\|X\|_F = \sqrt{ \sum_{i_1} \sum_{i_2} \cdots \sum_{i_k} X_{i_1, i_2, \dots, i_k}^2 }
$$

### 8.3 代码等价性严格证明
```python
# 手动利用开方和平方和验证
manual_norm = torch.sqrt(torch.sum(X ** 2))
assert torch.allclose(torch.linalg.norm(X), manual_norm)
print("习题 8 验证通过: 完全等价于 sqrt(sum(X ** 2))")
```
无论张量是何种高维形态，该函数都会将它视为“一维长扁平数组”，先对所有数值求平方，然后全部累加相加，最后开平方根，输出一个**标量**。
