## 二、PyTorch 查阅文档四大核心武器

### 2.1 武器一：探索模块内所有属性与函数 —— `dir()`
当我们导入一个陌生子模块，想要快速感知它提供了哪些功能时，使用 Python 内置的 `dir()` 函数：
```python
import torch

# 查看随机分布模块下的所有公开类与函数
print(dir(torch.distributions))
```
* **过滤法则**：
  * **忽略 `__xxx__`（双下划线）**：属于 Python 内置特殊方法/魔术属性（如 `__doc__`, `__name__` 等）；
  * **忽略 `_xxx`（单下划线）**：通常为内部私有函数或辅助实现；
  * **关注常规命名**：如 `Bernoulli`、`Normal`、`Multinomial`、`Uniform` 等，一眼即可看出该模块支持伯努利分布、正态分布、多项分布和均匀分布等采样。

---

### 2.2 武器二：查看函数规范与签名文档 —— `help()`
当知道某个函数名，但不确定其输入参数类型、默认值、输出形状时，使用 `help()` 函数：
```python
# 打印 torch.ones 的完整 API 文档说明与示例
help(torch.ones)
```
* **核心解析点**：
  * **函数签名**：`ones(*size, *, out=None, dtype=None, layout=torch.strided, device=None, requires_grad=False) -> Tensor`
  * **位置参数**：`*size` 接收张量形状（如 `(2, 3)` 或单独数字 `5`）；
  * **关键字参数**：
    * `dtype`：指定数值精度（如 `torch.float32`）；
    * `device`：指定运算设备（CPU 还是 CUDA GPU）；
    * `requires_grad`：是否加入自动求导计算图（默认为 `False`）。
* **快速验证**：
```python
torch.ones(4)  # tensor([1., 1., 1., 1.])
```

### 2.3 武器三：Jupyter 专属交互快捷查询 —— `?` 与 `??`
在 Jupyter Notebook / JupyterLab / IPython 环境下，提供了比标准终端更快捷的内联帮助：
1. **单问号 `?`（显示文档与签名）**：
   ```python
   torch.ones?
   ```
   * 会在下方或右侧呼出精美的帮助浮窗（Pager），展示文档字符串、函数签名与所在文件路径。
2. **双问号 `??`（穿透直接查看源码实现）**：
   ```python
   from d2l import torch as d2l
   d2l.plot??
   ```
   * 如果该函数是由 Python 实现的，`??` 会直接将该函数的**完整底层 Python 源代码**直接渲染出来！这是阅读开源库与优质项目最强大的学习神器。

## 三、课后练习题精解

### 练习 1：在深度学习框架中查找任何函数或类的文档。请尝试在这个框架的官方网站上找到文档。

#### 1. 框架内多维度查询实践（以优化器 `torch.optim.Adam` 为例）
```python
import torch
import torch.optim as optim

# 1. 查看 optim 模块包含的所有优化算法
print([name for name in dir(optim) if not name.startswith('_')])
# 输出: ['ASGD', 'Adadelta', 'Adagrad', 'Adam', 'AdamW', 'Adamax', 'LBFGS', 'NAdam', 'RAdam', 'RMSprop', 'Rprop', 'SGD', ...]

# 2. 查看 Adam 类的使用规范与超参数
help(optim.Adam)
# 可以看到 lr=0.001, betas=(0.9, 0.999), eps=1e-08, weight_decay=0 等核心超参数与更新公式
```

#### 2. 官方网站查找对应页面
* **官网文档路径**：访问 PyTorch Docs -> 左侧目录导航至 `torch.optim` -> 点击 `Adam`；
* **在线链接**：[https://pytorch.org/docs/stable/generated/torch.optim.Adam.html](https://pytorch.org/docs/stable/generated/torch.optim.Adam.html)
* **官网文档包含的额外信息**：
  * 完整的 LaTeX 数学更新公式（一阶动量、二阶动量、偏差修正公式）；
  * 与论文《Adam: A Method for Stochastic Optimization》的原始对应关系；
  * `maximize`、`fused`（GPU 内核融合加速）等新版本扩展参数说明。
