## 一、为什么深度学习需要概率论？

在机器学习和深度学习中，确定性模型无法完全刻画现实世界的不确定性：
1. **数据中的随机噪声**：如低分辨率图像识别（在 10×10 像素下难以区分猫和狗，分类判断具有不确定性）。
2. **本质上的随机现象**：如天气预测明天是否下雨。
3. **模型的置信度度量**：分类模型输出的 Softmax 分数本质上就是对各类别的后验概率估计 $P(y=k \mid \mathbf{x})$。

## 二、核心概率理论与贝叶斯推断机制

### 2.1 基础公理与运算规则
* **样本空间 $\mathcal{S}$ 与事件 $A$**：概率满足非负性 $P(A) \ge 0$、规范性 $P(\mathcal{S}) = 1$、互斥可加性。
* **加法法则（容斥原理）**：
  $$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$
* **条件概率定义与乘法法则**：
  $$P(A \mid B) = \frac{P(A \cap B)}{P(B)} \implies P(A, B) = P(B) P(A \mid B) = P(A) P(B \mid A)$$
* **边际化（全概率公式）**：
  $$P(B) = \sum_{A} P(A, B) = \sum_{A} P(B \mid A) P(A)$$

---

### 2.2 贝叶斯定理（Bayes' Theorem）
$$\text{后验概率 } P(H \mid D) = \frac{P(D \mid H) P(H)}{P(D)} = \frac{\text{似然 (Likelihood)} \times \text{先验 (Prior)}}{\text{证据 (Evidence / 边际似然)}}$$

#### 典型陷阱：基本比率谬误（Base Rate Fallacy）
在极其罕见疾病（如患病率 $P(H=1) = 0.0015$）的筛查中：
- 即使测试准确率高达 99%（假阳性率仅 1%），**单次阳性后真正患病的几率也仅有 13.06%**！
- 原因：人群基数中健康人占比高达 99.85%，健康人群产生的“假阳性绝对人数”远远压倒了患病人群的“真阳性人数”。
- **解决方案**：引入独立的第二次测试 $D_2$。在条件独立性假设下，连续两次误诊的概率为 $0.01 \times 0.03 = 0.0003$，此时双阳性后验患病率将飙升至 **83.07%**！

## 三、课后练习题深度精解（全 4 题）

### 练习 1：进行 $m=500$ 组实验，每组抽取 $n=10$ 个样本。改变 $m$ 和 $n$，观察和分析实验结果。

#### 1. 理论与物理意义分析
* 掷一个公平的 6 面骰子，理论上每个面出现的概率为 $p = 1/6 \approx 0.1667$。
* **参数 $n$（每组抽样样本数 / 批量大小）的影响**：
  * 当 $n$ 较小（如 $n=1$ 或 $n=10$）时，单组实验内的频数离散度大、方差大；
  * 当 $n$ 增大（如 $n=100$ 或 $1000$）时，每组实验本身就具备很高的统计稳定性，概率估计值围绕 $1/6$ 的波动幅度显著收窄。
* **参数 $m$（实验组数 / 迭代步数）的影响**：
  * $m$ 决定了累积观测到的总样本规模 $N = m \times n$；
  * 根据**大数定律（Law of Large Numbers）**与**中心极限定理（CLT）**，累积样本均值的方差正比于 $\mathcal{O}(1/\sqrt{m \times n})$。随 $m$ 增长，累积估计曲线必然单调收敛于水平虚线 $y = 0.167$。

#### 2. 代码对比实验
```python
import torch
from torch.distributions import multinomial
from d2l import torch as d2l
import matplotlib.pyplot as plt

fair_probs = torch.ones([6]) / 6

# 对比四组配置: (m=100, n=2), (m=500, n=10), (m=100, n=100), (m=500, n=100)
configs = [(100, 2), (500, 10), (100, 100), (500, 100)]
plt.figure(figsize=(12, 8))

for idx, (m, n) in enumerate(configs, 1):
    counts = multinomial.Multinomial(n, fair_probs).sample((m,))
    cum_counts = counts.cumsum(dim=0)
    estimates = cum_counts / cum_counts.sum(dim=1, keepdims=True)
    
    plt.subplot(2, 2, idx)
    for i in range(6):
        plt.plot(estimates[:, i].numpy(), label=f"P(die={i+1})")
    plt.axhline(y=0.167, color='black', linestyle='dashed')
    plt.title(f"m = {m} groups, n = {n} samples/group (Total: {m*n})")
    plt.xlabel('Groups of experiments')
    plt.ylabel('Estimated probability')
    if idx == 1:
        plt.legend()

plt.tight_layout()
plt.show()
```

#### 3. 核心结论
总样本量 $N = m \times n$ 决定了最终收敛的精度；而单组样本数 $n$ 决定了初始阶段的波动剧烈程度。$n$ 越大，起步曲线越平滑；$m$ 越大，后期收敛越精确。

### 练习 2：给定两个概率为 $P(A)$ 和 $P(B)$ 的事件，计算 $P(A \cup B)$ 和 $P(A \cap B)$ 的上限和下限。（提示：使用维恩图展示这些情况。）

#### 1. 数学推导与上下限界限

由概率的基本公理及容斥原理：
$$P(A \cup B) = P(A) + P(B) - P(A \cap B)$$
且对于任意概率，满足 $0 \le P(E) \le 1$。

#### (1) 对于交集 $P(A \cap B)$：
* **上限（Upper Bound）**：
  - 交集包含于各自事件之中，即 $A \cap B \subseteq A$ 且 $A \cap B \subseteq B$。
  - 因此 $P(A \cap B) \le P(A)$ 且 $P(A \cap B) \le P(B)$。
  - **最大可能值为较小集合被完全包含在大集合内时**：
    $$\max P(A \cap B) = \min(P(A), P(B))$$
* **下限（Lower Bound，Fréchet 不等式 / Bonferroni 不等式）**：
  - 由 $P(A \cup B) \le 1$ 可知：
    $$P(A \cap B) = P(A) + P(B) - P(A \cup B) \ge P(A) + P(B) - 1$$
  - 同时概率必须非负（$P(A \cap B) \ge 0$），当两事件互斥（$A \cap B = \emptyset$）时取得 0。
  - 综上：
    $$\min P(A \cap B) = \max(0, P(A) + P(B) - 1)$$

#### (2) 对于并集 $P(A \cup B)$：
* **下限（Lower Bound）**：
  - 并集必然包含各自的事件，即 $A \subseteq A \cup B$ 且 $B \subseteq A \cup B$。
  - 当一个事件完全被另一个事件包含时取到最小值：
    $$\min P(A \cup B) = \max(P(A), P(B))$$
* **上限（Upper Bound）**：
  - 由容斥原理 $P(A \cup B) \le P(A) + P(B)$，且概率不可能超过 1。
  - 当两事件互斥或总和超过样本空间时：
    $$\max P(A \cup B) = \min(1, P(A) + P(B))$$

#### 2. 维恩图（Venn Diagram）几何情形说明
* **极端情况 1（完全重叠/子集关系）**：
  - $B \subset A$（若 $P(B) \le P(A)$）：此时 $A \cap B = B$，$P(A \cap B)$ 达到最大值 $P(B)$；而 $A \cup B = A$，$P(A \cup B)$ 达到最小值 $P(A)$。
* **极端情况 2（尽可能互斥/无重叠）**：
  - 两椭圆完全分离（$A \cap B = \emptyset$）：此时 $P(A \cap B) = 0$ 达到最小值；$P(A \cup B) = P(A) + P(B)$ 达到最大值。
  - 若 $P(A) + P(B) > 1$，两集合受限于整个样本空间矩形框，必须有重叠，最少重叠面积为 $P(A) + P(B) - 1$，此时并集布满全空间 $P(A \cup B) = 1$。

### 练习 3：假设我们有一系列随机变量，例如 $A, B$ 和 $C$，其中 $B$ 只依赖于 $A$，而 $C$ 只依赖于 $B$，能简化联合概率 $P(A, B, C)$ 吗？（提示：这是一个马尔可夫链。）

#### 1. 严格推导过程
根据概率的**链式法则（Chain Rule）**，任意三个随机变量的联合概率总能展开为：
$$P(A, B, C) = P(A) P(B \mid A) P(C \mid A, B)$$

#### 2. 利用马尔可夫性质简化
* 条件中指出：“$C$ 只依赖于 $B$”。在马尔可夫链（Markov Chain）模型中，这构成了有向图 $A \to B \to C$。
* 形式化表达为**条件独立性（Conditional Independence）**：
  - **在给定当前状态 $B$ 的条件下，$C$ 与过去的 $A$ 条件独立**，即：
    $$P(C \mid A, B) = P(C \mid B)$$
* 代入链式展开式，得到极简形式：
  $$P(A, B, C) = P(A) P(B \mid A) P(C \mid B)$$

#### 3. 现实意义与机器学习启示
- 这就是著名的**马尔可夫性质（无后效性）**：“未来只依赖于现在，而与过去无关”。
- 在强化学习（RL）中，环境转移状态 $P(s_{t+1} \mid s_t, a_t)$ 就是典型的马尔可夫决策过程（MDP）；
- 在自然语言处理（NLP）的大语言模型中，自回归生成的 N-gram 语言模型和隐马尔可夫模型（HMM）均基于此简化，将指数级复杂度参数降低至仅依赖前驱状态的线性因子相乘。

### 练习 4：在 2.6.2 节中，第一个测试更准确。为什么不运行第一个测试两次，而是同时运行第一个和第二个测试？

这是一个关于**条件独立性假设在现实工程中何时成立**的关键问题。

#### 1. 致命原因：同一种测试很难满足“条件独立性”
* 在 2.6.2 节中，贝叶斯公式能够直接相乘的前提是：**在给定患者患病/健康的条件下，两次测试结果是相互独立的**。
  $$P(D_1=1, D_2=1 \mid H=0) = P(D_1=1 \mid H=0) \times P(D_2=1 \mid H=0)$$
* 如果对**同一个患者**用**同一种测试仪器（测试 1）重复运行两次**：
  - 假阳性往往不是完全由随机量子涨落产生的，而是由**患者体内的特定生化特征**引起的（例如体内含有某种特殊的抗体、交叉反应蛋白质、自身免疫病因子、血液样本污染或仪器对特定酸碱度敏感等）。
  - **如果一个健康人因为自身血液特质导致测试 1 误报阳性，那么 5 分钟后用相同的测试 1 再测一次，极大概率还是会误报阳性**！
  - 此时两次测试**高度正相关（严重不独立）**：
    $$P(D_{1b}=1 \mid D_{1a}=1, H=0) \gg 0.01$$
  - 重复测同一种测试，并不能有效消除系统性偏倚（Systematic Error / Bias）。

#### 2. 采用不同机理测试（测试 2）的战略优势
* 测试 1 和测试 2 通常采用**完全不同的检测原理或靶标**（例如：测试 1 采用免疫胶体金试纸初筛抗体，测试 2 采用核酸 PCR 扩增或蛋白印迹 Western Blot 检测病毒基因片段）。
* 两个不同原理的测试面临的干扰因素不同，极难同时对同一个健康人误报；
* 因此测试 1 与测试 2 之间的**条件独立性假设在现实中更加成立**，能够真正利用贝叶斯法则将假阳性概率压低至万分之三（$0.01 \times 0.03 = 0.0003$），大幅提升诊断置信度。
