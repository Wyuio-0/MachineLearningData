## 一、线性回归的四大核心要素

任何机器学习模型都可以抽象为以下四个关键要素：
1. **模型（Model）**：
   - 仿射变换（Affine Transformation）：预测值 $\hat{y} = \mathbf{w}^\top \mathbf{x} + b$
   - 包含权重向量 $\mathbf{w} \in \mathbb{R}^d$ 和偏置标量 $b \in \mathbb{R}$。
2. **训练数据（Training Data）**：
   - 特征矩阵 $\mathbf{X} \in \mathbb{R}^{n \times d}$，标签向量 $\mathbf{y} \in \mathbb{R}^n$。
3. **损失函数（Loss Function）**：
   - 平方误差损失（Squared Loss）：
     $$l^{(i)}(\mathbf{w}, b) = \frac{1}{2}\left(\hat{y}^{(i)} - y^{(i)}\right)^2$$
   - 数据集经验风险（均值损失）：
     $$L(\mathbf{w}, b) = \frac{1}{n}\sum_{i=1}^n \frac{1}{2}\left(\mathbf{w}^\top \mathbf{x}^{(i)} + b - y^{(i)}\right)^2$$
4. **优化算法（Optimization Algorithm）**：
   - 解析解（正规方程直接求解，仅限简单线性凸优化）；
   - 小批量随机梯度下降（Mini-batch SGD，适用于深度学习所有模型）。

## 二、解析解 vs 随机梯度下降（SGD）

### 2.1 解析解（Analytical Solution）
将偏置 $b$ 合并入权重向量 $\mathbf{w}$（在特征矩阵 $\mathbf{X}$ 末尾追加全 1 列），优化目标化为矩阵二范数极小化：
$$\min_{\mathbf{w}} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|^2$$
对 $\mathbf{w}$ 求导并令梯度为 0，得到正规方程解析解：
$$\mathbf{w}^* = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y}$$

### 2.2 小批量随机梯度下降（Mini-batch SGD）
在大规模深度学习中，解析解因求逆复杂度 $\mathcal{O}(d^3)$ 且无法推广到非线性网络而失效。SGD 通过负梯度迭代更新：
$$\mathbf{w} \leftarrow \mathbf{w} - \frac{\eta}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \mathbf{x}^{(i)} \left(\mathbf{w}^\top \mathbf{x}^{(i)} + b - y^{(i)}\right)$$
$$b \leftarrow b - \frac{\eta}{|\mathcal{B}|} \sum_{i \in \mathcal{B}} \left(\mathbf{w}^\top \mathbf{x}^{(i)} + b - y^{(i)}\right)$$
* **超参数（Hyperparameter）**：学习率 $\eta$ 和批量大小 $|\mathcal{B}|$（手动预先指定，通过验证集评估调优）。

## 三、矢量化加速（Vectorization）与基准测试

在模型训练中，必须避免在 Python 中使用显式 `for` 循环遍历样本，而应使用底层的张量矢量化运算：
* **底层原理**：矢量化调用底层高度优化的 BLAS/LAPACK/MKL 库，充分利用 CPU 的 SIMD（单指令多数据）向量寄存器或 GPU 流多处理器（SM）并行计算。
* **速度差异**：在 $n = 10,000$ 维向量按元素相加的基准测试中，矢量化 `+` 操作比 Python 原生 `for` 循环**快数百倍（约 0.0004s vs 0.167s）**！

## 四、核心定理：均方误差与正态分布极大似然估计（MLE）的等价性

为什么线性回归默认采用平方损失？这一设计源于**高斯噪声假设**。

1. **假设观测标签包含服从正态分布的随机噪声**：
   $$y = \mathbf{w}^\top \mathbf{x} + b + \epsilon, \quad \text{其中 } \epsilon \sim \mathcal{N}(0, \sigma^2)$$
2. **似然函数（Likelihood）**：
   $$P(y \mid \mathbf{x}) = \frac{1}{\sqrt{2\pi\sigma^2}} \exp\left(-\frac{1}{2\sigma^2} (y - \mathbf{w}^\top \mathbf{x} - b)^2\right)$$
3. **整个数据集的负对数似然（Negative Log-Likelihood, NLL）**：
   $$-\log P(\mathbf{y} \mid \mathbf{X}) = \sum_{i=1}^n \frac{1}{2}\log(2\pi\sigma^2) + \frac{1}{2\sigma^2}\sum_{i=1}^n \left(y^{(i)} - \mathbf{w}^\top \mathbf{x}^{(i)} - b\right)^2$$
4. **结论**：
   - 第一项为常数，第二项前面的系数 $1/\sigma^2$ 不影响极值点位置。
   - **最小化负对数似然（极大似然估计 MLE）在数学上严格等价于最小化均方误差（MSE）！**

## 五、神经网络视角的线性回归

* **网络结构**：单层神经网络（计算层数时不统计输入层，仅包含 1 个全连接输出神经元）。
* **特征维度**：输入层神经元数为 $d$。
* **生物学类比**：
  - 树突（输入 $\mathbf{x}_i$） $\to$ 突触加权（权重 $w_i$） $\to$ 细胞核累加（$\sum w_i x_i + b$） $\to$ 轴突输出。

## 六、课后练习题深度精解（全 3 题）

### 练习 1：寻找常数 $b$ 最小化 $\sum_{i=1}^n (x_i - b)^2$

#### 1. 找到最优值 $b$ 的解析解
设目标函数为 $f(b) = \sum_{i=1}^n (x_i - b)^2$。
对标量 $b$ 求导：
$$f'(b) = \frac{d}{db}\sum_{i=1}^n (x_i - b)^2 = \sum_{i=1}^n 2(x_i - b)(-1) = -2\sum_{i=1}^n (x_i - b)$$
令导数为 0：
$$-2\sum_{i=1}^n (x_i - b) = 0 \implies \sum_{i=1}^n x_i - n \cdot b = 0 \implies b^* = \frac{1}{n}\sum_{i=1}^n x_i$$
* **结论**：最优常数 $b^*$ 就是所有数据的**样本均值（Sample Mean）** $\bar{x}$！

#### 2. 这个问题及其解与正态分布有什么关系？
* **统计学意义**：若假设观测数据独立同分布来自于高斯分布 $x_i \sim \mathcal{N}(\mu, \sigma^2)$，则其对数似然函数为：
  $$\log P(\mathbf{x} \mid \mu, \sigma^2) = -\frac{n}{2}\log(2\pi\sigma^2) - \frac{1}{2\sigma^2}\sum_{i=1}^n (x_i - \mu)^2$$
* 极大似然估计 $\mu$（使对数似然最大）等价于最小化 $\sum_{i=1}^n (x_i - \mu)^2$。
* 因此，**最优解 $b^* = \bar{x}$ 正是正态分布均值 $\mu$ 的极大似然估计量（MLE）**！

### 练习 2：推导无偏置线性回归的解析解

#### 1. 矩阵向量表示
给定输入数据矩阵 $\mathbf{X} \in \mathbb{R}^{n \times d}$ 和标签向量 $\mathbf{y} \in \mathbb{R}^n$，优化目标为：
$$L(\mathbf{w}) = \frac{1}{2n}\|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 = \frac{1}{2n}(\mathbf{y} - \mathbf{X}\mathbf{w})^\top (\mathbf{y} - \mathbf{X}\mathbf{w})$$
展开得：
$$L(\mathbf{w}) = \frac{1}{2n}\left(\mathbf{y}^\top \mathbf{y} - 2\mathbf{w}^\top \mathbf{X}^\top \mathbf{y} + \mathbf{w}^\top \mathbf{X}^\top \mathbf{X} \mathbf{w}\right)$$

#### 2. 计算损失对 $\mathbf{w}$ 的梯度
应用矩阵微分公式 $\nabla_\mathbf{w} (\mathbf{a}^\top \mathbf{w}) = \mathbf{a}$ 和 $\nabla_\mathbf{w} (\mathbf{w}^\top \mathbf{A} \mathbf{w}) = (\mathbf{A} + \mathbf{A}^\top)\mathbf{w}$：
$$\nabla_\mathbf{w} L(\mathbf{w}) = \frac{1}{n}\left(-\mathbf{X}^\top \mathbf{y} + \mathbf{X}^\top \mathbf{X} \mathbf{w}\right)$$

#### 3. 求解解析解
令梯度为 $\mathbf{0}$：
$$\mathbf{X}^\top \mathbf{X} \mathbf{w} = \mathbf{X}^\top \mathbf{y}$$
当 $\mathbf{X}^\top \mathbf{X}$ 可逆时，左右同乘逆矩阵：
$$\mathbf{w}^* = (\mathbf{X}^\top \mathbf{X})^{-1} \mathbf{X}^\top \mathbf{y}$$

#### 4. 什么时候解析解比 SGD 更好？何时失效？
* **解析解更好的场景**：
  * 特征维度 $d$ 较小（如 $d < 10,000$）、样本量 $n$ 可以完整放入内存时；
  * 解析解是一步到位的精确极值解，无需调整学习率、无需迭代、没有局部极小困扰。
* **解析解失效或劣于 SGD 的场景**：
  1. **不可逆 / 奇异矩阵（Singular）**：当样本数小于特征数（$n < d$）或特征间存在多重共线性（线性相关）时，$\mathbf{X}^\top \mathbf{X}$ 奇异不可逆，无法求唯一解（需引入伪逆或岭回归正则化）；
  2. **高维灾难（计算复杂度）**：求逆复杂度为 $\mathcal{O}(d^3)$，当 $d$ 达到数十万（如现代深度学习中的大模型参数），矩阵求逆在算力和显存上不可行；
  3. **海量流式数据**：样本量 $n$ 极大（亿级）无法一次性载入内存时，SGD 按批次流式训练更实用。

### 练习 3：指数分布（拉普拉斯分布）噪声下的回归问题

假定附加噪声 $\epsilon$ 服从对称指数分布（拉普拉斯分布 Laplace Distribution）：$p(\epsilon) = \frac{1}{2}\exp(-|\epsilon|)$。

#### 1. 写出负对数似然（NLL）
模型为 $y = \mathbf{w}^\top \mathbf{x} + b + \epsilon$。在给定 $\mathbf{x}$ 下，$y$ 的条件概率密度为：
$$P(y \mid \mathbf{x}) = \frac{1}{2}\exp\left(-|y - \mathbf{w}^\top \mathbf{x} - b|\right)$$
所有样本的负对数似然：
$$-\log P(\mathbf{y} \mid \mathbf{X}) = -\sum_{i=1}^n \log\left(\frac{1}{2}\exp\left(-|y^{(i)} - \mathbf{w}^\top \mathbf{x}^{(i)} - b|\right)\right) = n\log 2 + \sum_{i=1}^n |y^{(i)} - \mathbf{w}^\top \mathbf{x}^{(i)} - b|$$
* **核心洞察**：拉普拉斯噪声下的极大似然估计**严格等价于最小化绝对值误差损失（Mean Absolute Error, MAE / L1 损失）**，也称中位数回归（Median Regression）。

#### 2. 解析解分析
* 绝对值函数在残差等于 0 处不可导；
* 整体目标函数是分段线性的非平滑凸函数，**不存在类似正规方程的简单显式解析解（Closed-form Solution）**；
* 需要通过**线性规划（Linear Programming, LP）**的单纯形法或内点法来求得数值精确解。

#### 3. SGD 算法设计及驻点问题解决
* **梯度计算（次梯度 Subgradient）**：
  $$g(\mathbf{w}) = \frac{1}{|\mathcal{B}|}\sum_{i \in \mathcal{B}} -\mathbf{x}^{(i)} \cdot \text{sgn}\left(y^{(i)} - \mathbf{w}^\top \mathbf{x}^{(i)} - b\right)$$
  其中 $\text{sgn}(u)$ 为符号函数（$u>0$ 为 $1$，$u<0$ 为 $-1$，$u=0$ 处次梯度可在 $[-1, 1]$ 之间任选，通常取 0）。
* **哪里可能出错（驻点震荡问题）**：
  * 因为绝对值函数的导数大小恒为 $\pm 1$，当参数接近最优点（残差很小）时，梯度的模长**不会像平滑平方误差那样自动缩小到接近 0**！
  * 固定的学习率会导致参数在最优点两侧不断发生跳跃与**剧烈震荡（Oscillation）**，无法精确收敛。
* **解决方案**：
  1. **动态衰减学习率（Learning Rate Decay）**：令学习率随迭代步数逐步衰减（如 $\eta_t = \frac{\eta_0}{\sqrt{t}}$），步长收缩消除震荡；
  2. **平滑替代（Huber Loss / Smooth L1 Loss）**：在误差较小区间（如 $|u| < \delta$）切换为平滑的平方损失，在误差较大区间保持线性抗离群点干扰。
