## 一、为什么必须“从零开始实现（from scratch）”？

现代深度学习框架（如 PyTorch、TensorFlow、JAX）提供了高度封装的高层抽象（`nn.Linear`、`nn.MSELoss`、`optim.SGD`、`DataLoader`）。但如果直接依赖黑盒封装，开发者往往会忽视底层关键机制：
1. **梯度是如何在参数上累加和手动清零的**；
2. **张量形状广播（Broadcasting）与维度对齐（Reshape）潜藏的隐形 Bug**；
3. **参数就地更新（In-place update）与 `torch.no_grad()` 上下文脱钩计算图的深层原理**；
4. **自定义模型架构、损失函数或优化规则时的底层自由度**。

## 二、从零实现六大核心模块分解与原理透视

### 2.1 模块一：合成带噪声的数据集流水线（`synthetic_data`）
* **数学设定**：
  真实权重 $\mathbf{w}^* = [2, -3.4]^\top$，真实偏置 $b^* = 4.2$。生成 1000 个样本，每个样本包含 2 个标准正态分布特征 $\mathbf{x} \sim \mathcal{N}(\mathbf{0}, \mathbf{I})$：
  $$y = \mathbf{w}^\top \mathbf{x} + b + \epsilon, \quad \epsilon \sim \mathcal{N}(0, 0.01^2)$$
* **代码实现**：
```python
def synthetic_data(w, b, num_examples):
    """生成 y = Xw + b + 噪声"""
    X = torch.normal(0, 1, (num_examples, len(w)))
    y = torch.matmul(X, w) + b
    y += torch.normal(0, 0.01, y.shape)
    return X, y.reshape((-1, 1))
```
> **注意细节**：标签 `y` 必须通过 `.reshape((-1, 1))` 显式保持为二维列向量 $(1000, 1)$，坚决防止后续与行向量发生隐式广播错乱！

---

### 2.2 模块二：小批量数据迭代器（`data_iter`）
* **设计意图**：每次从数据集中抽取固定大小 `batch_size` 的样本块供模型前向和反向传播，既利用了矢量化并行，又引入了梯度随机性（Stochasticity）帮助跳出劣质局部极值。
* **代码实现（Python 生成器 `yield`）**：
```python
import random

def data_iter(batch_size, features, labels):
    num_examples = len(features)
    indices = list(range(num_examples))
    random.shuffle(indices)  # 打乱样本索引，保证每个 epoch 读取次序随机
    for i in range(0, num_examples, batch_size):
        batch_indices = torch.tensor(indices[i: min(i + batch_size, num_examples)])
        yield features[batch_indices], labels[batch_indices]
```
> **思考点**：这种基于索引切片切内存的方式适合小型数据集；工业界中如果数据达几十 GB，需使用内存映射或多线程数据流（如 PyTorch 的 `DataLoader`）。

---

### 2.3 模块三：参数初始化与梯度追踪
```python
# 权重从均值为 0、标准差为 0.01 的高斯分布中采样，偏置初始化为 0
w = torch.normal(0, 0.01, size=(2, 1), requires_grad=True)
b = torch.zeros(1, requires_grad=True)
```
* 开启 `requires_grad=True` 后，后续所有基于 `w` 和 `b` 的前向运算都会被自动构建进动态计算图。

---

### 2.4 模块四：模型前向与平方损失定义
* **模型定义**（矩阵乘法 + 偏置广播加法）：
```python
def linreg(X, w, b):
    """线性回归模型"""
    return torch.matmul(X, w) + b
```
* **损失函数定义**：
```python
def squared_loss(y_hat, y):
    """均方误差损失"""
    return (y_hat - y.reshape(y_hat.shape)) ** 2 / 2
```
> **防坑核心**：`y.reshape(y_hat.shape)` 是工业级防御性编程。如果 `y_hat` 是 `(N, 1)` 而 `y` 是 `(N,)`，直接做减法会触发 NumPy/PyTorch 的广播机制变成 `(N, N)` 的巨大矩阵，导致显存爆炸且损失计算彻底错误！

---

### 2.5 模块五：小批量随机梯度下降优化器（`sgd`）
```python
def sgd(params, lr, batch_size):
    """小批量随机梯度下降"""
    with torch.no_grad():               # 1. 禁用梯度追踪，更新参数不记录入计算图
        for param in params:
            param -= lr * param.grad / batch_size  # 2. 用批量平均梯度就地更新参数
            param.grad.zero_()          # 3. 极其重要：手动将梯度清零！
```
* **为什么除以 `batch_size`？** 因为损失求和 `l.sum()` 得到的是整批样本的总损失，其导数是整批样本梯度的总和。除以批量大小对梯度做归一化，使得学习率 `lr` 的步长独立于批量大小的选择。
* **为什么必须 `param.grad.zero_()`？** PyTorch 默认机制是累加梯度，不在每一步清零会导致历史梯度越积越大，训练彻底发散。

---

### 2.6 模块六：完整训练循环与真实参数恢复对比
```python
lr = 0.03
num_epochs = 3
net = linreg
loss = squared_loss

for epoch in range(num_epochs):
    for X, y in data_iter(batch_size, features, labels):
        l = loss(net(X, w, b), y)       # 计算该批次的损失向量 (batch_size, 1)
        l.sum().backward()              # 标量反向传播，将各样本梯度累加到 [w.grad, b.grad]
        sgd([w, b], lr, batch_size)     # 执行一步梯度更新并清零梯度
    
    with torch.no_grad():
        train_l = loss(net(features, w, b), labels)
        print(f'epoch {epoch + 1}, loss {float(train_l.mean()):f}')
```
* **训练评估**：
  仅需 3 个迭代周期（epoch），损失就从 `0.042` 迅速收敛到 `0.00005`。
  $w$ 的估计误差与真实值 $[2, -3.4]$ 相比仅在 $10^{-4}$ 量级，偏置 $b$ 误差仅 $10^{-3}$，完美恢复出数据背后的本质规律！

### 练习 1：如果我们将权重初始化为零，会发生什么？算法仍然有效吗？

#### 1. 理论深度分析
* **在线性回归（单层单神经元网络）中**：
  * 若初始化 $\mathbf{w} = \mathbf{0}, b = 0$；
  * 第一步前向预测为 $\hat{y} = \mathbf{X}\mathbf{0} + 0 = 0$；
  * 损失函数导数为 $\nabla_\mathbf{w} l = \frac{1}{|\mathcal{B}|}\mathbf{X}^\top(\hat{\mathbf{y}} - \mathbf{y}) = -\frac{1}{|\mathcal{B}|}\mathbf{X}^\top \mathbf{y}$；
  * 各特征分量接收到的梯度为 $-\frac{1}{|\mathcal{B}|}\sum x_j^{(i)} y^{(i)}$，**只要各特征本身的分布不同，计算出的梯度就各不相同**！
  * **结论：对于单层线性回归，初始化为零算法依然完全有效，且能顺利收敛到最优解！**
* **在深层多层感知机（MLP / 深度神经网络）中**：
  * 若将多神经元隐藏层的权重全部初始化为 0，会导致**对称性破坏失效（Symmetry Breaking Problem）**：同一个隐藏层内的所有神经元将获得完全相同的输入、完全相同的激活输出和完全相同的梯度，导致整个隐藏层退化为一个神经元，丧失特征提取能力。

#### 2. 代码验证
```python
# 验证线性回归权重全零初始化
w_zero = torch.zeros((2, 1), requires_grad=True)
b_zero = torch.zeros(1, requires_grad=True)
for epoch in range(3):
    for X, y in data_iter(batch_size, features, labels):
        l = squared_loss(linreg(X, w_zero, b_zero), y)
        l.sum().backward()
        sgd([w_zero, b_zero], 0.03, batch_size)
print("零初始化后训练得到的 w:", w_zero.squeeze().detach().numpy())
# 输出完美逼近真实权重 [2.0, -3.4]!
```

### 练习 2：假设试图为电压和电流的关系建立一个模型。自动微分可以用来学习模型的参数吗？

#### 1. 物理模型与参数学习
* **欧姆定律（线性模型）**：
  $$U = I \cdot R$$
  * 测量不同电流 $I$ 下的电压 $U$ 数据对 $\{(I_i, U_i)\}$。
  * 将电阻 $R$ 作为待学习参数，定义模型 $\hat{U} = I \cdot R$，损失函数 $l = \frac{1}{2}(\hat{U} - U)^2$。
  * 自动微分完全可以自动求出 $\frac{\partial l}{\partial R} = (\hat{U} - U)I$，利用梯度下降精确拟合电阻 $R$。
* **非线性电子元件（二极管 Shockley 方程）**：
  $$I = I_S \left( \exp\left(\frac{qU}{n k_B T}\right) - 1 \right)$$
  * 包含反向饱和电流 $I_S$ 和理想因子 $n$ 等多个高度非线性的待定物理参数。
  * **传统手工求导极其繁琐，而自动微分（Autograd）天然支持复合函数的指数与链式法则**，构建动态计算图后调用 `.backward()`，即可直接用梯度下降反演非线性物理参数！

### 练习 3：能基于普朗克定律（Planck's Law）使用光谱能量密度来确定物体的温度吗？

#### 1. 物理原理与反演问题（Inverse Problem）
* **普朗克辐射定律**：黑体在绝对温度 $T$ 下，波长 $\lambda$ 的单色光谱辐射能量密度为：
  $$B(\lambda, T) = \frac{2hc^2}{\lambda^5} \frac{1}{\exp\left(\frac{hc}{\lambda k_B T}\right) - 1}$$
  其中普朗克常数 $h$、光速 $c$、玻尔兹曼常数 $k_B$ 均为已知物理常数，$\lambda$ 为可测量的电磁波波长。
* **基于自动微分确定温度 $T$ 的步骤**：
  1. 通过光谱仪在多个波长测得一组能量辐射观测值 $\{(\lambda_i, B_{\text{obs}, i})\}$；
  2. 将物体温度 $T$ 设为可训练的标量张量（`T = torch.tensor([300.0], requires_grad=True)`）；
  3. 定义拟合损失函数：$L(T) = \sum_i (B(\lambda_i, T) - B_{\text{obs}, i})^2$；
  4. 利用 PyTorch 自动微分计算关于温度的导数 $\frac{\partial L}{\partial T}$，使用梯度下降或高斯-牛顿法优化更新 $T$。
* **工程挑战与注意事项**：
  * 指数项 $\exp(\dots)$ 在初值设置不当时极易发生**数值上溢（Overflow）**；
  * 需使用对数域或对物理常数进行**无量纲化归一化缩放（Nondimensionalization）**，并给出一个合理的先验温度初始值。

### 练习 4：计算二阶导数时可能会遇到什么问题？这些问题可以如何解决？

#### 1. 潜在问题与计算瓶颈
1. **显存与计算复杂度爆炸**：
   * 一阶导数是维度为 $d$ 的梯度向量；二阶导数是 $d \times d$ 的**海森矩阵（Hessian Matrix）** $\mathbf{H}_{ij} = \frac{\partial^2 L}{\partial w_i \partial w_j}$。
   * 存储复杂度为 $\mathcal{O}(d^2)$，计算复杂度为 $\mathcal{O}(d^3)$。当神经网络参数 $d=10^7 \sim 10^{11}$ 时，存储和求逆海森矩阵在物理硬件上完全不可行。
2. **非凸性与鞍点陷阱（Saddle Points）**：
   * 在深度神经网络的高维损失曲面上，非局部极小值的鞍点（Hessian 矩阵既有正特征值又有负特征值）极其普遍。标准的牛顿法会直接朝着负特征值方向（局部极大值方向）迭代导致发散。
3. **高阶计算图开销**：
   * 必须设置 `retain_graph=True` 和 `create_graph=True`，内存占用翻倍。

#### 2. 解决方案
* **拟牛顿法（Quasi-Newton Methods，如 L-BFGS）**：不直接计算海森矩阵，而是仅用过去若干步的一阶梯度变化来隐式逼近海森矩阵的逆；
* **无矩阵海森乘积（Hessian-Free Optimization / HVPs）**：通过前向模式或反向自动微分，只计算海森矩阵与特定向量的乘积 $\mathbf{H}\mathbf{v}$，复杂度降回到 $\mathcal{O}(d)$；
* **一阶算法加动量替代**：在深度学习实践中，直接采用 Adam / AdamW / SGD+Momentum 等一阶动量算法代替昂贵的二阶优化。

### 练习 5：为什么在 `squared_loss` 函数中需要使用 `reshape` 函数？

#### 1. 致命的隐式广播机制（Broadcasting Trap）
* 假设输入预测值 `y_hat` 的形状为二维列向量 `(batch_size, 1)`（例如 `(10, 1)`）；
* 如果标签向量 `y` 在某些数据管线中是一维行向量 `(batch_size,)`（例如 `(10,)`）；
* **如果不加 `reshape` 直接执行 `y_hat - y`**：
  * PyTorch 会触发**广播对齐规则**：
    `y_hat (10, 1)` 沿列复制 10 次变成 `(10, 10)`；
    `y (10,)` 沿行复制 10 次变成 `(10, 10)`；
  * 相减结果变成了一个 **$10 \times 10$ 的方阵**！包含 100 个元素！
  * 紧接着执行 `l.sum()`，不仅损失值放大且完全错误，而且梯度计算将变成跨样本错位交叉求导，模型完全无法收敛！
* **防御性编程**：
  强制执行 `y.reshape(y_hat.shape)`，确保两者同为严格对齐的形状（`(batch_size, 1)`），避免由于维度不慎导致的广播隐形灾难。

### 练习 6：尝试使用不同的学习率，观察损失函数值下降的快慢。

* **实验对比**：
  1. **过小学习率（如 $\text{lr} = 0.001$）**：参数更新步长极其微弱，3 个 epoch 之后损失依然高达 1.83，远未收敛；
  2. **最佳学习率（如 $\text{lr} = 0.03 \sim 0.1$）**：损失在每个 epoch 呈现指数级稳健下降，迅速逼近全局最优；
  3. **过大学习率（如 $\text{lr} = 1.1$）**：单步更新剧烈跨越损失函数谷底，导致梯度与损失在后续步骤瞬间爆炸，输出 `nan` 或 `inf`（梯度爆炸）。

### 练习 7：如果样本个数不能被批量大小整除，`data_iter` 函数的行为会有什么变化？

#### 1. 行为分析
* 在 `data_iter` 中切片逻辑为：
  `indices[i: min(i + batch_size, num_examples)]`
* 当样本总数 $N=1000$，若设置 `batch_size = 300`：
  - 第 1 批：索引 `0 ~ 300`（样本量 300）
  - 第 2 批：索引 `300 ~ 600`（样本量 300）
  - 第 3 批：索引 `600 ~ 900`（样本量 300）
  - **最后一批**：`indices[900: min(900+300, 1000)]` 即 `indices[900: 1000]`，**样本量仅为 100**！

#### 2. 对训练的影响与处理
* **影响**：最后一个批次由于只有 100 个样本，在除以传入的固定 `batch_size=300` 时，等效的单样本梯度权重缩小了 3 倍，使得这 100 个样本在该轮的更新幅度变小；
* **主流解决方案**：
  1. **动态批量归一化**：在 `sgd` 中使用当前批次的真实样本数 `len(X)` 替代全局常数 `batch_size`；
  2. **丢弃最后残缺批次**：在 PyTorch 官方 `DataLoader` 中设置 `drop_last=True`，直接丢弃无法整除的最后一小批。
