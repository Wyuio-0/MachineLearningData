### 3-1 构成强化学习的马尔可夫决策过程的四元组有哪些变量？

在《Easy RL》教材中，马尔可夫决策过程（MDP）常被提炼为四元组 $\langle S, A, P, R \rangle$（若考虑长远利益折现，则常扩展为经典的五元组 $\langle S, A, P, R, \gamma \rangle$）：

1. **$S$（State space，状态空间）**：智能体在环境中所可能处在的全部状态集合（比如棋盘的所有可能残局、小车的所有可能位置与速度）。
2. **$A$（Action space，动作空间）**：智能体在特定状态下所允许做出的所有可能决策/动作集合（比如上、下、左、右）。
3. **$P$（State transition probability，状态转移概率）**：$P(s' \mid s, a)$，表示在当前状态 $s$ 做出动作 $a$ 之后，物理环境转移到下一状态 $s'$ 的条件概率。
4. **$R$（Reward function，奖励函数）**：$R(s, a)$ 或 $R(s, a, s')$，表示智能体在状态 $s$ 执行动作 $a$ 时，环境所反馈给它的即时标量奖励（奖惩信号）。
*(注：$\gamma \in [0, 1)$ 为折扣因子，负责权衡当前即时奖励与未来远期收益的权重)*。

### 3-2 请通俗地描述强化学习的“学习”流程。

如果把强化学习的智能体比作一个**“在迷宫中摸索的小老鼠”**，它的学习过程本质上是**“试错、撞墙、扣分、改错”**的闭环循环：

1. **观察环境（看一眼）**：智能体感知当前所处的位置状态 $s$；
2. **权衡决策（挑一步）**：翻开脑海中的“得分日记本（Q表）”，以大概率选择历史评分最高的动作，但保留一小部分概率（$\epsilon$-贪心）去尝试新路线（探索）；
3. **付诸行动（踩一脚）**：执行动作 $a$，环境即时给出反馈——如果吃到奶酪给正奖励 $r$，掉进水坑给负惩罚，并把你送到了新格子 $s'$；
4. **反思差距（算误差）**：将**“眼前真正拿到的肉干 $r$ + 下一步新格子的预期分数”**（现实真相），与之前日记本里盲猜的分数进行对比，算出误差（时序差分误差 TD-Error）；
5. **更新记忆（改笔记）**：根据学习率 $\alpha$，把日记本里当前格子的 Q 值朝真实方向修正一点点；
6. **循环千万次（终成大师）**：通过海量探索，整张地图所有格子的最佳走向全部清晰定型，小老鼠掌握了闭着眼睛也能以最高分通关的最优策略。

### 3-3 请描述基于 Sarsa 算法的智能体的学习过程。

**Sarsa** 的名字来源于其单步更新所用到的五个变量：$(s_t, a_t, r_{t+1}, s_{t+1}, a_{t+1})$ 的首字母缩写。它的学习流程极其强调**“言行一致”**：

1. **初始动作选择**：在状态 $s$，利用 $\epsilon$-贪心策略挑选动作 $a$；
2. **环境交互**：执行动作 $a$，环境反馈即时奖励 $r$，并转移到新状态 $s'$；
3. **决定下一步真实动作（关键特征！）**：在刚到达的新状态 $s'$ 上，**立刻再次使用 $\epsilon$-贪心策略**预先挑选出下一步将要执行的动作 $a'$（但先不执行）；
4. **Q 值更新**：用这个真实即将执行的动作价值 $Q(s', a')$ 来计算更新目标：
   $$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ \mathbf{r + \gamma Q(s', a')} - Q(s, a) \right]$$
5. **推进状态与动作**：将状态更新为 $s \leftarrow s'$，动作更新为 $a \leftarrow a'$，进入下一轮循环。

### 3-4 Q 学习（Q-Learning）算法和 Sarsa 算法的区别是什么？

这是各大名企和科研面试中**最高频考题**！核心区别体现在**“更新机制”**与**“性格行为”**上：

#### 1. 核心数学更新目标不同
* **Sarsa（言行一致）**：
  $$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \mathbf{Q(s', a')} - Q(s, a) \right]$$
  更新时参考的 $a'$，是它下一步**真的会去走的动作**（可能包含 $\epsilon$ 随机探索的翻车动作）。
* **Q-Learning（只看理想极限）**：
  $$Q(s, a) \leftarrow Q(s, a) + \alpha \left[ r + \gamma \mathbf{\max_{a'} Q(s', a')} - Q(s, a) \right]$$
  更新时**完全不看下一步实际走哪**，直接粗暴取下一步所有选择里的理论最高分 $\max$！

#### 2. 行为性格对比（以悬崖寻路 Cliff Walking 为例）
* **Sarsa 是个“谨小慎微的保守派”**：
  因为它知道自己在走下一步时还有 $\epsilon$ 概率会“手抖乱按”，为了防止手抖掉下悬崖扣 100 分，它最终会学出一条**“离悬崖远远的安全环形路线”**。
* **Q-Learning 是个“大胆激进的冒险家”**：
  它在更新时假定自己下一步永远是绝对理性的最优解（$\max$），因此它毫不畏惧，会直接学出紧贴着悬崖边缘走的最短完美路线（即使在训练探索期掉悬崖也死不改悔）。

### 3-5 同策略（On-policy）和异策略（Off-policy）的区别是什么？

强化学习中有两个极其关键的策略概念：
* **行为策略（Behavior Policy）**：负责真正下场玩游戏、收集经验、控制手柄的策略；
* **目标策略（Target Policy）**：大脑正在反思、评估和试图训练优化的策略。

| 对比维度 | 同策略 (On-policy) | 异策略 (Off-policy) |
| :--- | :--- | :--- |
| **策略关系** | **行为策略 == 目标策略**（两身合一） | **行为策略 $\neq$ 目标策略**（两者分离） |
| **通俗话语** | “自己一边实践，一边总结自己当下的打法” | “你在台上乱试错，但你脑子里在推演理想大神的打法” |
| **典型代表** | **Sarsa**（用 $\epsilon$-greedy 玩，学的也是 $\epsilon$-greedy） | **Q-Learning**（用 $\epsilon$-greedy 探索玩，但学的是贪心最优策略 $\max$） |
| **数据复用能力** | **极差**：必须边玩边学，过去的旧数据（旧策略生成的）不可复用。 | **极强**：可以复用过去的旧录像、甚至人类高手的操作数据（支持**经验回放**，DQN 的基石）。 |

### 💡 核心深度思考：为什么时序差分能用“下一步的 Q 值”更新“这一步的 Q 值”？（自举 Bootstrapping）

* **初学者困惑**：刚开始两个 Q 都是瞎猜的，拿瞎猜的更新瞎猜的，岂不是套娃？
* **破局关键：偷渡了一滴真实真理**：
  * 在 $r + \gamma Q(s', a')$ 中，虽然 $Q(s', a')$ 是猜的，**但即时奖励 $r$ 是实打实从环境拿到的真实物理事实**！
  * 相比于在原地纯靠脑补，“1 步真实事实 + 后面的猜想”绝对比纯脑补更准一点点。
* **波浪倒灌机制**：
  * 真实奖励（如掉悬崖的 -100，或到达终点的 +10）就像墨水滴在纸上；
  * 每一轮时序差分更新，把这个绝对真理向外倒灌一格，最终全局所有 Q 值都会在折扣因子 $\gamma < 1$ 的收缩作用下，严格收敛至最优真值。

### 3-5 友善的面试官：请简述一下时序差分方法 (Temporal-Difference, TD)。
**【参考高分回答】**
* **一句话定义**：时序差分（TD）是强化学习中**结合了动态规划的“自举（Bootstrapping）”和蒙特卡洛的“采样（Sampling）”思想的核心无模型方法**。
* **运作精髓（单步在线自举）**：
  智能体无需等待一整局游戏分出胜负，每与环境交互走完一步（得到真实即时奖励 $r_{t+1}$ 并看到下一状态 $s_{t+1}$），**立刻结合下一状态的打折预估值作为参考靶心**，就地更新当前状态的价值：
  $$V(S_t) \leftarrow V(S_t) + \alpha \left[ \mathbf{R_{t+1} + \gamma V(S_{t+1})} - V(S_t) \right]$$
* **时序差分误差（TD-Error，$\delta_t$）**：
  $$\delta_t = R_{t+1} + \gamma V(S_{t+1}) - V(S_t)$$
  它直观衡量了“走完一步看到的现实新局面”与“之前在起点的旧预测”之间的认知落差。

### 3-6 友善的面试官：请问蒙特卡洛方法和时序差分方法是无偏估计吗？另外谁的方差更大呢？为什么？
**【参考高分回答】**

#### 1. 偏差（Bias）对比
* **蒙特卡洛（MC）是无偏估计（Unbiased，0 偏差）**：
  MC 用整局游戏打完收官后的真实累积总分 $G_t$ 进行更新，根据大数定律，$\mathbb{E}[G_t \mid S_t = s] = V(s)$，完全没有使用任何脑补猜想，因此是严格无偏的。
* **时序差分（TD）是有偏估计（Biased，有偏差）**：
  TD 使用了自举项 $V(S_{t+1})$，这个值本身是由网络或表格在当前不成熟阶段预测出来的，包含了模型当前的估计误差，因此单步更新是有偏的（随着不断迭代，偏差逐步收缩趋于 0）。

#### 2. 方差（Variance）对比：蒙特卡洛的方差远大于时序差分！
* **为什么 MC 方差极大？**
  从当前步直到游戏终局，经历了数十甚至上千步连续的状态转移随机性与动作随机性。多步随机扰动层层相乘累加，导致走同一盘棋两局的最终得分大起大落，方差极大；
* **为什么 TD 方差极小？**
  TD 每次仅经历 1 步真实物理交互，只承担当前 1 步的环境微小扰动，后续未来的复杂性被平滑地封装在 $V(S_{t+1})$ 中，因此更新曲线非常平稳、样本抖动小。
