# 《Easy RL：强化学习教程》第二章 马尔可夫决策过程 核心笔记

## 1. 核心概念深剖：“满足马尔可夫条件”到底是什么意思？

在强化学习中，说一个实际问题或任务“**满足马尔可夫决策过程（MDP）的条件**”，最核心的本质就是指它满足：**马尔可夫性（Markov Property，在数学上也称无后效性）**。

> **一句话精髓**：
> **“只要看清了现在，过去的历史就可以彻底翻篇；预测未来的下一秒，完全不需要翻看过去的旧账。”**

### 1.1 数学公式拆解：消掉历史包袱
在条件概率中，严格的马尔可夫条件定义如下：

$$P(s_{t+1}, r_{t+1} \mid s_t, a_t, \color{red}{s_{t-1}, a_{t-1}, \dots, s_0, a_0}) = P(s_{t+1}, r_{t+1} \mid s_t, a_t)$$

* **等式左边**：如果要预测下一刻的状态 $s_{t+1}$ 和奖励 $r_{t+1}$，必须参考从游戏开始到现在的**全部历史流水账（红色部分）**；
* **等式右边**：历史流水账被**直接剔除**，只保留了当前的 $s_t$ 与动作 $a_t$；
* **含义**：**“现在的状态”是自足且充分的（Sufficient Statistic）**，它已经浓缩了所有做出决策所需的历史信息，多看历史对预测未来毫无额外帮助。

### 1.2 直观案例对比

#### ✅ 满足条件的例子：象棋残局
* 面对一个象棋残局，无论两个高手此前厮杀了多长时间（历史完全未知），只要看一眼此时此刻棋盘上每个棋子的坐标（**当前状态 $s_t$**），就完全能够推演出下一步的所有走法与输赢走向。
* **结论**：当前棋盘布局已经包含了做出决策所需要的全部信息。

#### ❌ 不满足条件的例子：只给单张照片的自动驾驶
* 自动驾驶摄像头拍到斑马线前有一辆车，如果状态 $s$ 仅仅被定义为**当前瞬间的一张静态图片**，AI 根本无法预测下一秒这辆车会撞过来还是已停稳，因为**丢失了时间维度的历史信息（速度、加速度）**。
* **如何将其改造成满足马尔可夫性？**
  * 扩展状态的定义：将状态由单张图片改成 `[当前位置, 当前速度, 当前加速度]`；
  * 一旦将速度和加速度打包进“当前状态”，数据再次自足，问题就**重新满足了马尔可夫条件**！

### 1.3 为什么强化学习一定要追求“满足马尔可夫条件”？
1. **消除算力爆炸**：如果不满足马尔可夫性，AI 做每一步决策都必须背着一本无限膨胀的“历史日记本”，算法复杂度会直接崩塌。
2. **贝尔曼方程的前提**：后续所有的动态规划与值函数迭代公式（$V(s) = R + \gamma V(s')$），其递归形式的成立**唯一且绝对依赖于马尔可夫假设**。

## 2. 核心架构演变：从“随波逐流”到“自主决策”的三级跳

第二章展现了强化学习数学模型的演进脉络：

```text
马尔可夫过程 (MP) ➡️ 马尔可夫奖励过程 (MRP) ➡️ 马尔可夫决策过程 (MDP)
 (无奖励、无选择)       (有奖励、但无选择)          (既有奖励，又有自主选择)
```

| 模型分类 | 数学元组 | 通俗比喻 | 核心区别与机制 |
| :--- | :--- | :--- | :--- |
| **1. 马尔可夫过程 (MP)** | $\langle S, P \rangle$ | **看落叶随水漂流** | 只有“状态”与自然“转移概率”。没有好坏打分，智能体无法施加任何干预。 |
| **2. 马尔可夫奖励过程 (MRP)** | $\langle S, P, R, \gamma \rangle$ | **看不能选号的彩票** | 引入**奖励函数 $R$** 与 **折扣因子 $\gamma$**。虽然仍不能自主选择，但各状态开始有了价值分值（诞生了基础贝尔曼方程）。 |
| **3. 马尔可夫决策过程 (MDP)** | $\langle S, A, P, R, \gamma \rangle$ | **自己驾驶赛车** | **正式引入动作空间 $A$！** 智能体通过策略 $\pi(a\|s)$ 主动介入环境改变状态转移，追求长期累积回报最大化。 |

## 3. 巧思转换：已知策略 $\pi$ 时，如何把 MDP 降维转化成 MRP？

书中有一个非常重要但容易让初学者困惑的推导：**已知 MDP 和策略 $\pi$，可以直接消掉动作 $a$，将 MDP 转换回 MRP。**

### 3.1 通俗比喻：从“自己握方向盘”到“开启自动驾驶”
* **MDP（亲力亲为）**：你亲自开赛车，在路口（状态 $s$）踩油门还是打方向（动作 $a$）由你实时决定；
* **固定策略 $\pi$（开启巡航）**：按下了自动驾驶按钮。系统内置习惯：遇到路口，70% 概率左转，30% 概率直行；
* **退化为 MRP（乘客视角）**：你把手拿开当乘客。在旁观者看来，车到路口后“自然而然”以 70% 概率去左边、30% 概率去右边。**主动的“动作决策”被概率抹平了，整个系统退化成了一个无动作的自然随机流转过程（MRP）**。

### 3.2 数学公式：加权平均（边缘化）消掉 $a$
既然知道了在状态 $s$ 采取各个动作的概率 $\pi(a \mid s)$，就可以把原本依赖动作的转移函数和奖励函数进行**加权求和**：

* **状态转移概率消除 $a$**：
  $$P^\pi(s' \mid s) = \sum_{a \in A} \pi(a \mid s) P(s' \mid s, a)$$
* **奖励函数消除 $a$**：
  $$R^\pi(s) = \sum_{a \in A} \pi(a \mid s) R(s, a)$$

### 3.3 为什么要做这个降维转换？
* **把复杂博弈变成线性方程**：在带动作 $a$ 的 MDP 里，价值函数计算繁琐；
* 一旦消掉 $a$ 变成 MRP，贝尔曼方程就变成了初中生都能理解的线性代数形式：
  $$V^\pi = R^\pi + \gamma P^\pi V^\pi$$
* 此时计算机甚至不需要反复迭代，直接利用矩阵求逆公式即可一步求出所有状态的价值：
  $$V^\pi = (I - \gamma P^\pi)^{-1} R^\pi$$

## 4. 灵魂核心：贝尔曼方程 (Bellman Equation)

贝尔曼方程是强化学习理论大厦的承重墙，其核心逻辑为：
> **“当前状态的长期价值 = 眼前立马拿到的即时奖励 + 走向下一状态的折现期望”**

### 4.1 贝尔曼期望方程（用于固定策略评估）
在给定策略 $\pi$ 下，状态价值 $V^\pi(s)$ 与动作价值 $Q^\pi(s, a)$ 形成交织递归：
* $V^\pi(s) = \sum_{a \in A} \pi(a \mid s) Q^\pi(s, a)$
* $Q^\pi(s, a) = R(s, a) + \gamma \sum_{s' \in S} P(s' \mid s, a) V^\pi(s')$

### 4.2 贝尔曼最优方程（用于寻找最强决策）
寻优时去掉了按概率加权平均，直接采用贪心思想取 **$\max$（最大值）**：
* $V^*(s) = \max_{a \in A} Q^*(s, a)$
* $Q^*(s, a) = R(s, a) + \gamma \sum_{s' \in S} P(s' \mid s, a) V^*(s')$

**直观含义**：最理想局面的价值，等于在这个局面下**做出最好的那一手选择**所带来的全额价值。

## 5. 终极任务：MDP 要解决的两大问题

| 核心问题 | 别名 / 学术称谓 | 输入条件 | 解决的核心疑问 |
| :--- | :--- | :--- | :--- |
| **预测问题 (Prediction)** | **策略评估 (Policy Evaluation)** | 给定具体策略 $\pi$ | “如果我就按当前这套习惯一直走，在各个局面下到底能拿多少分？” |
| **控制问题 (Control)** | **策略寻优 (Optimal Control)** | 仅给环境 MDP 模型 | “在所有可能的操作中，哪一套策略（最优策略 $\pi^*$）能夺得全场最高分？” |
